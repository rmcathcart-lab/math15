Types of Slope: Positive, Negative, Zero, and Undefined

Every line has one of four types of slope, and you can spot the type before you calculate anything. Read the line from left to right: uphill is positive, downhill is negative, flat is zero, and straight up is undefined. Today’s big idea: zero is an answer; undefined means there is no answer.

I can…
  • tell whether a line rises or falls from left to right, and match it to a positive or negative slope
  • calculate a slope with the formula and explain its sign: same signs give a positive slope, opposite signs a negative one
  • explain why a horizontal line has a slope of 0 and a vertical line has an undefined slope
  • write the equation of a horizontal line (y=k) or a vertical line (x=k)
  • sort segments on one grid into the four types, then confirm with the formula

Positive Slope and Negative Slope

Slope compares rise to run. Always read a line from left to right.
\text{slope}=\dfrac{\color{#7b4fc4}\text{rise}}{\color{#c27a0e}\text{run}}=\dfrac{\text{change in }y}{\text{change in }x}
Positive slope: the line rises from left to right. As x increases, y increases, so rise and run have the same sign. Their quotient is positive.
Negative slope: the line falls from left to right. As x increases, y decreases, so rise and run have opposite signs. Their quotient is negative.
!
Sign rules for dividing. (+)\div(+)=(+) and (-)\div(-)=(+): same signs, positive. (-)\div(+)=(-) and (+)\div(-)=(-): opposite signs, negative.
Example 1

A rising segment

Segment CD: C(-4,-3), D(2,3).

(a) Left to right, does it rise or fall?
It rises.
(b) Calculate the slope of CD. Is it positive or negative, and does that match (a)?
m=\dfrac{y_2-y_1}{x_2-x_1}=\dfrac{3-(-3)}{2-(-4)}=\dfrac{6}{6}=\boldsymbol{1}
Positive, and the line rises, so it matches (a).
Example 2

A falling segment

Segment EF: E(-4,3), F(2,-3). It has the same run as CD, but it falls.

(a) Left to right, does it rise or fall?
It falls.
(b) Calculate the slope of EF.
m=\dfrac{-3-3}{2-(-4)}=\dfrac{-6}{6}=\boldsymbol{-1}
(c) Compare it to the slope of CD: what is the same, what is different, and why does that make sense?
Same run (6) and same steepness, but the sign is opposite: 1 vs. -1. EF drops 6 instead of climbing 6, so its rise is -6 and the quotient is negative.
Negatives on the calculator. Put brackets around the top and the bottom, and use (−) for a negative number: ((−)3−3)÷(2−(−)4)ENTER gives -1.

Zero Slope vs. Undefined Slope

These two are the pair most often mixed up.

A horizontal line is flat. Every point has the same y-coordinate, so the rise is always 0 and \text{slope}=\tfrac{0}{\text{run}}=0. Zero is a real, perfectly ordinary number. The line’s equation is y=k.
A vertical line runs straight up and down. Every point has the same x-coordinate, so the run is always 0 and \text{slope}=\tfrac{\text{rise}}{0}. Dividing by 0 gives no number at all, so the slope is undefined: it does not exist. The line’s equation is x=k.
Zero is an answer; undefined means there is no answer.
Flat like the horizon → slope 0
Straight up like a flagpole → undefined

Why can’t we divide by 0?

Division undoes multiplication: 6\div3=2 because 2\times3=6. So to divide by 0, we need a number that gives an answer when it is multiplied by 0.

Ask the calculator. 0÷4ENTER gives 0. But 4÷0ENTER gives DIVIDE BY 0, an error: there is no number to show.
Example 3

A horizontal line

A horizontal line through G(-4,2), H(0,2), I(3,2).

(a) Calculate the slope of GH, of HI, and of GI.
m_{GH}=\dfrac{2-2}{0-(-4)}=\dfrac{0}{4}=\boldsymbol{0}
m_{HI}=\dfrac{2-2}{3-0}=\dfrac{0}{3}=\boldsymbol{0}
m_{GI}=\dfrac{2-2}{3-(-4)}=\dfrac{0}{7}=\boldsymbol{0}
(b) All three agree. Why must that happen for any two points on this line?
Every point on a horizontal line has the same y-value, so the rise is always 0; and 0 divided by any run (that isn’t 0) is 0.
(c) Equation of the line: y=2
\boldsymbol{y=2}: every point on it has y=2.
Example 4

A vertical line

A vertical line through J(-2,4), K(-2,0), L(-2,-3).

(a) Calculate the slope of JK, of KL, and of JL.
The run is -2-(-2)=0 every time:
m_{JK}=\dfrac{0-4}{0}=\dfrac{-4}{0}
m_{KL}=\dfrac{-3-0}{0}=\dfrac{-3}{0}
m_{JL}=\dfrac{-3-4}{0}=\dfrac{-7}{0}
All three are undefined.
(b) All three agree. Why must that happen for any two points on this line?
Every point has the same x-value, so the run is always 0, and dividing by 0 never gives a number.
(c) Equation of the line: x=-2
\boldsymbol{x=-2}: every point on it has x=-2.

Any two points agree

Key ideas

Read left to right. A line that rises has a positive slope; a line that falls has a negative slope.
The sign comes from rise and run. Same signs: positive. Opposite signs: negative. A mirror flip keeps the steepness and changes the sign (1 and -1).
Horizontal: slope 0. The rise is always 0, and \tfrac{0}{\text{run}}=0. Equation y=k. Flat like the horizon.
Vertical: undefined. The run is always 0, and we can’t divide by 0. Equation x=k. Zero is an answer; undefined means no answer.
