Classifying Systems: One Solution, No Solution, or Infinite Solutions

Two lines don’t always cross once. They can cross once, never (parallel lines), or lie exactly on top of each other. The slopes and y-intercepts tell you which, without drawing a thing.

I can…
  • explain why two lines with different slopes cross exactly once: one solution
  • recognize parallel lines (same slope, different y-intercepts): no solution
  • recognize the same line in disguise (same slope, same y-intercept): infinitely many solutions
  • rewrite an equation like 2x+2y=8 as y=mx+b, dividing every term when needed
  • classify a system without graphing: compare the slopes first, then the y-intercepts
RF9 Solve problems that involve systems of linear equations in two variables, graphically and algebraically.

1

One Solution: Different Slopes

Two lines with different slopes are tilted by different amounts. Wherever they start, the gap between them closes, so they must cross, and after that the gap only grows: they cross only once. The system has exactly one solution: the crossing point. This is by far the most common case.

Example 1

Different slopes

Consider the system y=2x-1 and y=-x+5.

(b) Graph both lines on the grid.
y=2x-1: start at (0,\ -1), then up 2, right 1.
y=-x+5: start at (0,\ 5), then down 1, right 1.
(a) State the slope of each line. Are the slopes the same or different?
y=2x-1: m_1=\boldsymbol{2}. y=-x+5: m_2=\boldsymbol{-1}.
The slopes are different, so the lines must cross exactly once.
(c) State the point where the lines cross. This is the solution to the system.
The lines cross at \boldsymbol{(2,\ 3)}: one solution.
Check: 2(2)-1=3 ✓ and -(2)+5=3 ✓

Example 1 check: graph both, then count the crossings

Plot each y-intercept, step out the slope, draw the line. Then count the points that are on both lines.

Even when the crossing is off the grid

Some lines with different slopes look parallel on a small grid. They still cross: the crossing is just far away. Compare the slopes, not the picture.

Think The warm-up’s pencil question: can two different straight lines cross at exactly two points?
No. After two straight lines cross, the gap between them only grows. If two lines shared two points, they would be the same line, and then they share every point. So the only possible counts are 1, 0, or infinitely many.
2

No Solution: Parallel Lines

Two lines are parallel exactly when they have the same slope. Equations with the same slope but different y-intercepts graph as parallel lines that stay the same distance apart forever and never meet: the system has no solution.

Example 2

Same slope, different intercepts

Consider the system y=3x+2 and y=3x-3.

(b) Graph both lines on the grid. What do you notice?
Both lines climb at the same steepness (up 3, right 1), so they stay the same distance apart forever: they are parallel and never touch.
(a) State the slope and y-intercept of each equation.
y=3x+2: m=\boldsymbol{3}, b=\boldsymbol{2}
y=3x-3: m=\boldsymbol{3}, b=\boldsymbol{-3}
Same slope, different y-intercepts.
(c) How many solutions does this system have?
A solution is a point on both lines, and there is no such point. The system has no solution.

Example 2 check: parallel lines

Same slope means the same steps: up 3, right 1 for both lines. Measure the gap between them anywhere.

3

Infinitely Many Solutions: The Same Line in Disguise

Two equations that look different can be the exact same line: one is just a multiple of the other, so the slopes and the y-intercepts match. One graph lands on top of the other, so every point on the line is a solution: infinitely many solutions.

When y has a number in front (like 2y or -2y): after moving the x-term, divide every term by that number. 2y=-2x+8\ \Rightarrow\ y=-x+4.
Example 3

Two equations, one line

Consider the system x+y=4 and 2x+2y=8. Notice that 2x+2y=8 is exactly 2\times(x+y=4).

(b) Graph both lines on the grid.
Both have m=-1 and b=4, so the second graph lands exactly on top of the first (drawn dashed over it).
(a) Rewrite both equations in slope y-intercept form.
x+y=4\ \Rightarrow\ \boldsymbol{y=-x+4}
2x+2y=8\ \Rightarrow\ 2y=-2x+8\ \Rightarrow\ \boldsymbol{y=-x+4} (divide every term by 2)
(c) How many solutions does the system have? Explain.
They are the same line, so every point on it makes both equations true: infinitely many solutions.

Example 3 check: one line, drawn twice

Rewrite the second equation first. Then graph both and look for the points they share.

4

Classifying a System Without Graphing

1Write both equations in slope y-intercept form, y=mx+b.
2Compare the slopes. Different slopes: one solution, and you can stop.
3Same slopes? Compare the y-intercepts. Different: no solution. Same: infinitely many.

Far faster than graphing!

!
Rewrite before you compare. 4x-2y=-2 and y=2x+1 look nothing alike, but they are the same line. Comparing numbers from two different forms (the 4 and the 2) gives the wrong answer.

✓

Key ideas

One solution. Different slopes: the lines must cross, and only once. The intercepts can be anything.
No solution. Same slope, different y-intercepts: parallel lines, always the same distance apart, never meeting.
Infinitely many. Same slope and same y-intercept: the same line in disguise. Every point on it is a solution.
Without graphing: rewrite both as y=mx+b (divide every term if y has a number in front). Compare slopes first, then intercepts. Never exactly two solutions.
