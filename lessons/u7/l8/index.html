Horizontal Lines: y=k

Every point on a horizontal line shares the same y-coordinate, so its equation is y=k and x never appears. (-3,4), (0,4) and (2,4) all lie on y=4, whatever the x-coordinate is.

Because y never changes as x changes, the rise is always 0: every horizontal line has slope 0.

x-504
y-3-3-3
x never appears, so y=-3 every time: (-5,-3), (0,-3), (4,-3).
(c) What is the slope of every horizontal line? 0
The rise between any two points is 0 (the y-values never change), so m=\dfrac{\text{rise}}{\text{run}}=\dfrac{0}{\text{run}}=\boldsymbol{0}.

Vertical Lines: x=k

Every point on a vertical line shares the same x-coordinate, so its equation is x=k and y never appears. (-2,-5), (-2,0) and (-2,6) all lie on x=-2.

Here x never changes while y does, so the run is 0, and rise over run would divide by zero: every vertical line has an undefined slope.

Telling y=k and x=k Apart

The letter missing from the equation is the direction the line is free to travel.

\boldsymbol{y=k} mentions no x, so x roams and y is pinned: the line is horizontal, slope 0.
\boldsymbol{x=k} mentions no y, so y roams and x is pinned: the line is vertical, slope undefined.

Before graphing, ask: “Which coordinate is held fixed?” If the fixed letter is x, the line is vertical, always.
!
The classic error is drawing x=3 as a flat line through 3 on the y-axis. Compare the two lines in the picture: both go through the number 3, but on different axes.

A Strategy for Graphing Any Linear Equation

Work through three questions, in order.

1
Is it y=k or x=k?
Graph it directly. No calculation.
2
Is it y=mx+b?
Plot (0,b), then count out the slope m as rise over run.
3
Is it Ax+By+C=0?
Rearrange into y=mx+b, or (usually faster) use the two-intercept method.
Two-intercept method for 2x+y-4=0: set y=0: 2x-4=0, so x=2 and the x-intercept is (2,0). Set x=0: y-4=0, so y=4 and the y-intercept is (0,4). Plot both and join them.

Now graph it

Each route ends the same way: two or more points, joined with a ruler, arrows on both ends.

Mixed Practice

Now the form is not announced: read the equation first, decide which of the three routes is cheapest, then graph. Constant-only equations (y=k, x=k) are the quickest of all: no table needed.

✓

Key ideas

Horizontal: y=k. No x in the equation. Every point has y=k; it crosses the y-axis at (0,k). Rise is always 0, so the slope is 0.
Vertical: x=k. No y in the equation. Every point has x=k; it crosses the x-axis at (k,0). Run is always 0, so the slope is undefined.
Which coordinate is held fixed? The missing letter is the direction the line travels. x=3 is vertical, never a flat line through 3 on the y-axis.
Any form, three questions. (1) y=k or x=k: graph directly. (2) y=mx+b: plot (0,b), count the slope. (3) Ax+By+C=0: two intercepts, join them.
