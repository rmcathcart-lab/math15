Review: Graphing Linear Equations from a Table of Values

A linear equation always makes a straight line. Pick some x-values, work out their y-values, plot the points and join them. And to check if a point is on a line, you don’t even need the graph.

I can…
  • tell a linear equation from a non-linear one by looking at what happens to x
  • build a table of values by substituting x-values into an equation
  • plot the ordered pairs from a table and join them with one straight line, all the way to the edges of the grid
  • decide whether a point lies on a line by substituting its coordinates

1

Linear and Non-Linear Equations

An ordered pair (x,\ y) locates a point. A relation is a set of such pairs, and its graph is the picture of those points. An equation is linear when its graph is a straight line. So y=2x+3 is linear, while y=x^2 is non-linear (its graph is a curve called a parabola).

In a linear equation, x appears only to the first power. It is never…

y=x^{\textcolor{#c93a33}{2}}squared or cubed
\textcolor{#c93a33}{x}y=6multiplied by another variable
y=\sqrt{\textcolor{#c93a33}{x}}under a root
y=\dfrac{1}{\textcolor{#c93a33}{x}}in a denominator
y=2^{\textcolor{#c93a33}{x}}an exponent

NON-LINEAR

The warm-up again: same step every time, straight line

A table tells you too. When x goes up by 1 each time, a linear equation’s y-values change by the same step every time, so the points line up. A non-linear one’s steps keep changing, so its points bend.

2

Building a Table of Values from an Equation

A table of values lists ordered pairs that make an equation true. Pick several x-values (usually -2,\ -1,\ 0,\ 1,\ 2), substitute each one into the equation, and simplify to get its y-value. Each column of the table is one ordered pair.
For y=x+3, this gives y=1,\ 2,\ 3,\ 4,\ 5: the pairs (-2,\ 1), (-1,\ 2), (0,\ 3), (1,\ 4) and (2,\ 5).
!
Brackets around every substituted value. For x=-2, write 2(-2)-3, not 2-2-3. The brackets keep the negative sign with the number: 2(-2)=-4.

Graphing a Line from a Table of Values

The workflow is always the same four steps:

1Pick x-values
2Substitute to get the y-values
3Plot the ordered pairs
4Join them with one straight line, out to the edges of the grid
!
Draw the whole line. Use a ruler, go all the way to the edges of the grid in both directions, and put arrows on the ends. The line keeps going: the five points are only a few of its points.

One point off the line? Check it again

Points from a linear equation always line up. If one of yours doesn’t, it isn’t the line’s fault: re-check that point’s arithmetic, then how you plotted it.

4

Checking Whether a Point Lies on a Line

No graph is needed. Substitute the point’s x-coordinate for x and its y-coordinate for y. If the statement is true, the point lies on the line. If it is false, the point does not.

Try it: on the line or not?

Pick a line, then tap any grid point. The substitution check tells you whether that point is on the line.

Example 5

On the line or not?

Determine whether each point lies on the given line.

(a) Does (3,\ 5) lie on y=x+2?
Substitute x=3, y=5:
5\overset{?}{=}3+2
5=5 ✓ true
Yes: (3,\ 5) lies on the line.
(b) Does (-2,\ 1) lie on y=3x+4?
Substitute x=-2, y=1:
1\overset{?}{=}3(-2)+4
1\overset{?}{=}-6+4=-2 ✗ false
No: (-2,\ 1) is not on the line.
(c) Does (-4,\ 1) lie on y=-2x-7?
Substitute x=-4, y=1:
1\overset{?}{=}-2(-4)-7
1\overset{?}{=}8-7=1 ✓ true
Yes: (-4,\ 1) lies on the line.

The warm-up’s big one: far, far away

A graph can’t tell (30,\ 90) from (30,\ 92): they are almost the same dot. Substitution can, in one line.

✓

Key ideas

Linear or not? In a linear equation, x is only to the first power: never squared, under a root, in a denominator or an exponent. Its graph is a straight line, and its y-values change by the same step each time.
Table of values. Pick x=-2,\ -1,\ 0,\ 1,\ 2, substitute each one in brackets, and simplify: y=2(-2)-3=-7. Each column is an ordered pair.
Graph it. Plot each pair (across by x, up or down by y), then join them with one straight line out to the edges, with arrows. A point off the line means a mistake.
On the line? Substitute both coordinates. 5\overset{?}{=}3+2 is true, so (3,\ 5) is on y=x+2. False means the point is not on the line.
