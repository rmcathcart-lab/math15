Classifying Numbers in the Real Number System

Every number has a home. Today we sort numbers into the sets they belong to (natural, whole, integer, rational, irrational, real), see how those sets fit inside each other, and put real numbers in order on a number line.

I can…
  • tell natural numbers, whole numbers and integers apart
  • write a number as a decimal and say whether it terminates or repeats
  • decide whether a number is rational or irrational, and explain why
  • name every set a number belongs to, using the nested-sets diagram
  • put real numbers in order and plot them on a number line

1

Natural Numbers, Whole Numbers, and Integers

Natural numbers N=\{1,\ 2,\ 3,\ \ldots\}
the counting numbers
Whole numbers W=\{0,\ 1,\ 2,\ 3,\ \ldots\}
add 0
Integers I=\{\ldots,\ -2,\ -1,\ 0,\ 1,\ 2,\ \ldots\}
add the opposites

Each set is tucked completely inside the next, so every natural number is also whole, and also an integer.

Example 1

Natural, whole, or integer?

Given the set \{-3,\ 0,\ 5,\ -11,\ 14,\ 20\}, list every member that is:

(a) a natural number
Counting numbers only (1, 2, 3, …):
5, 14, 20
(b) a whole number
The naturals together with 0:
0, 5, 14, 20
(c) an integer
Integers include the negatives, so all six:
−11, −3, 0, 5, 14, 20
2

Rational Numbers

A rational number Q is any number that can be written as a fraction \dfrac{a}{b} with a and b integers and b\neq0.
Every integer9=\tfrac{9}{1}
Every terminating decimal0.7=\tfrac{7}{10}
Every repeating decimal0.\overline{3}=\tfrac{1}{3}

So to check a number, write it as a decimal: if it terminates or repeats, it is rational.

A fraction as a decimal: it always terminates or repeats

Divide the top by the bottom. Watch the remainders: once one comes back, the digits repeat forever.

!
The bar goes over the repeating block only. 0.444\ldots=0.\overline{4} and 0.272727\ldots=0.\overline{27}.

Write each as a decimal, say whether it terminates or repeats, and explain why it is rational.

Terminates.
Rational: a ratio of two integers.
3

Irrational Numbers

An irrational number \overline{Q} has a decimal that runs on forever without ever settling into a repeating block.
\sqrt{2}=1.41421356\ldots \qquad \pi=3.14159265\ldots

A square root (of a whole number) is rational exactly when the number under the root is a perfect square: \sqrt{16}=4 is rational, but \sqrt{17} is irrational.

Does it ever repeat? Wrap the digits into rows and look for stripes

A repeating decimal lines up into neat stripes when you wrap it in rows the length of its block. An irrational number never does.

Rational or irrational? Ask one question at a time

!
A pattern is not a repeating block. 0.505\,005\,000\,5\ldots has a pattern, but the zeros keep growing, so no block of digits ever repeats.
Example 3

Rational or irrational?

Classify each number as rational or irrational, and explain your reasoning.

(a) \sqrt{2}
2 is not a perfect square, so \sqrt2=1.41421356\ldots never ends or repeats.
Irrational
(b) \sqrt{9}
9=3^2 is a perfect square, so \sqrt9=3=\tfrac31.
Rational
(c) \pi
\pi=3.14159265\ldots: the digits never end and never fall into a repeating block.
Irrational
(d) 0.505005000500005\ldots
The zeros keep growing, so no block of digits ever repeats.
Irrational

Chasing π with fractions

Around 250 BCE, the Greek mathematician Archimedes trapped a circle between two shapes with 96 sides, one inside it and one outside. That proved π is between 3\tfrac{10}{71} and 3\tfrac{1}{7}.

About 700 years later in China, Zu Chongzhi found \tfrac{355}{113}, which matches π to 6 decimal places. Nobody beat his work on π for about 900 years.

Is \tfrac{22}{7} (that’s 3\tfrac17) rational or irrational? Is it equal to π?
Rational: it’s a fraction, and its decimal repeats, \tfrac{22}{7}=3.\overline{142857}. π = 3.14159… never repeats, so \tfrac{22}{7} is only a close guess (it matches 2 decimal places).
4

The Real Number System

Together the rationals and the irrationals fill in every point on the number line: this collection is the set of real numbers R. The sets nest as N\subset W\subset I\subset Q\subset R, with \overline{Q} the only reals outside that chain. A number belongs to every set that contains it.

Build it one set at a time

Which sets is it in? Test from the outside in

Start with “real?” and work inward. The number lands in the deepest set it fits, and it also belongs to every set around that one.

Ordering and Comparing Real Numbers

Because the reals fill every point on the line, any two of them can be compared. Turn each number into a decimal. Estimate an irrational square root from the nearest perfect squares (\sqrt{2}\approx1.4), and watch for roots of perfect squares: -\sqrt{1}=-1 is rational, because 1 is a perfect square.

The Number Club

House rule: every guest goes to the deepest room they are allowed into. Tap a guest, then tap a room.

1
Send 7, 0 and -4 to their rooms.
7 → Natural (counting). 0 → Whole. −4 → Integers (negatives stop there).
2
Where do \tfrac{3}{5} and 0.25 go?
Both → Rational. \tfrac35=0.6 and 0.25=\tfrac14.
3
\sqrt{16} and \sqrt{2} look like twins. Same room?
No! \sqrt{16}=4 → Natural. \sqrt2=1.41421\ldots → Irrational.
!
The big one. The bouncer turns one of these guests away from the Rational room. Who? Guess first.
A 0.333\ldots
B \sqrt{49}
C \tfrac{22}{7}
D \pi
D: π = 3.14159… never ends and never repeats. A repeats (0.333\ldots=\tfrac13), B is \sqrt{49}=7, and C is a fraction: only a close guess for π.

Key ideas

Natural 1, 2, 3, … · Whole add 0 · Integers add the negatives. Each set sits inside the next.
Rational Q: can be written as \tfrac{a}{b}; its decimal terminates or repeats. Every integer is rational.
Irrational \overline{Q}: the decimal never ends and never repeats (\pi, \sqrt2). A square root of a whole number is rational only when that number is a perfect square.
Real R = rational + irrational: every point on the number line. A number belongs to every set that contains it. To order, compare the decimals.
