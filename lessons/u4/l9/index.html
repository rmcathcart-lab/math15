Solving Polynomial Equations by Factoring

All unit long, factoring has been expanding run backwards. Today it pays off: factoring solves equations. It all rests on one simple fact: if a product is 0, then one of the factors must be 0. That turns one hard equation into two easy ones.

I can…
  • explain the zero product property: if A\cdot B=0, then A=0 or B=0
  • solve an equation that is already factored, like (x-4)(x+7)=0
  • solve a quadratic equation by factoring: make one side 0, factor, set each factor equal to 0, and solve
  • rearrange an equation so one side is 0 before I factor it
  • check my solutions by substituting them into the original equation
AN5 Demonstrate an understanding of common factors and trinomial factoring, concretely, pictorially and symbolically.

1

The Zero Product Property

What times 7 gives 0? Only 0: if 7\times m=0, then m=0. In the same way, a product can only be zero when one of its factors is zero.

Zero Product Property: if A\cdot B=0, then A=0 or B=0.

Seeing it with x: try every value

In (x-3)(x+5), each bracket is a number once we pick x. Try lots of values of x and see when the product is 0.

Split it into two small equations

So (x-3)(x+5)=0 splits into x-3=0 or x+5=0. That gives two solutions (also called roots): x=3 and x=-5.

!
A number in front never gives a solution. In 4(x-5)(x+3)=0, the 4 can never be 0, so only the factors with an x matter. But a lone x is a factor: x(x-6)=0 gives x=0 or x=6.
Example 1

Equations that are already factored

Solve each equation using the Zero Product Property.

(a) (x-4)(x+7)=0
x-4=0 or x+7=0
\boldsymbol{x=4} or \boldsymbol{x=-7}
(b) (x+2)(x-9)=0
x+2=0 or x-9=0
\boldsymbol{x=-2} or \boldsymbol{x=9}
(c) (x+6)(x+1)=0
x+6=0 or x+1=0
\boldsymbol{x=-6} or \boldsymbol{x=-1}
(d) 4(x-5)(x+3)=0
The 4 gives no solution.
\boldsymbol{x=5} or \boldsymbol{x=-3}
Think Run it backwards: write an equation whose solutions are x=2 and x=-6.
x=2 comes from x-2=0, and x=-6 from x+6=0: \boldsymbol{(x-2)(x+6)=0}. Expanded, that is x^2+4x-12=0.
2

Solving Quadratic Equations by Factoring

Most equations don’t arrive already factored. That’s where everything from this unit comes in. The plan is always the same four steps:

1Make one side exactly 0.
2Factor the other side completely: GCF first, then difference of squares or trinomial.
3Set each factor equal to 0.
4Solve each small equation.

Every equation in Example 2 is already equal to 0, so we can start factoring right away.

Example 2

Factor, then split

Solve each equation by factoring.

(a) x^2-49=0
Difference of squares: (x-7)(x+7)=0
\boldsymbol{x=7} or \boldsymbol{x=-7}
(b) x^2+9x=0
Common factor x: x(x+9)=0
\boldsymbol{x=0} or \boldsymbol{x=-9} (don’t divide the x away: it is a solution)
(c) x^2-5x+6=0
Product 6, sum −5: -2 and -3. (x-2)(x-3)=0
\boldsymbol{x=2} or \boldsymbol{x=3}
(d) x^2+2x-24=0
Product −24, sum 2: 6 and -4. (x+6)(x-4)=0
\boldsymbol{x=-6} or \boldsymbol{x=4}

Don’t divide the x away

In Example 2(b) it is tempting to divide both sides by x. Watch what that does to the warm-up riddle, x^2=5x (“my square is 5 times me”).

!
Never divide both sides by x. It throws away the solution x=0. Move everything to one side and factor out the x instead.
3

Equations That Need Rearranging First

The zero product property only works when the product equals 0. You cannot split x(x+3)=10 into x=10 and x+3=10.

Move every term to one side

First move every term to one side, so the other side is 0. For example, x^2+5x=14 becomes x^2+5x-14=0. That factors as (x+7)(x-2)=0, so x=-7 or x=2.

Example 3

Rearrange, factor, split

Solve each equation. Rearrange first so that one side is 0.

(a) x^2+3x=10
x^2+3x-10=0
(x+5)(x-2)=0
\boldsymbol{x=-5} or \boldsymbol{x=2}
(b) x^2=8x-15
x^2-8x+15=0
(x-3)(x-5)=0
\boldsymbol{x=3} or \boldsymbol{x=5}
(c) x^2-4x=12
x^2-4x-12=0
(x-6)(x+2)=0
\boldsymbol{x=6} or \boldsymbol{x=-2}
Think Which equation is ready for the zero product property right now?

Checking Solutions by Substitution

Substitute each root back into the original equation, not the factored form. For x^2+5x=14: (-7)^2+5(-7)=49-35=14 ✓ and (2)^2+5(2)=4+10=14 ✓, so both roots are confirmed.

!
Brackets around negative numbers. (-3)^2=9, but -3^2 means -(3^2)=-9. Substitute with brackets every time.
Checking with a calculator (at home; the unit test is no-calculator). Check x=-3 in x^2-x: ((−)3)x²−((−)3)ENTER gives 12 ✓
Example 4

Solve, then check

Solve x^2-x=12 by factoring, then check both solutions in the original equation.

Solve:
x^2-x-12=0
Product −12, sum −1: -4 and 3
(x-4)(x+3)=0
\boldsymbol{x=4} or \boldsymbol{x=-3}
Check:
x=4: 4^2-4=16-4=12 ✓
x=-3: (-3)^2-(-3)=9+3=12 ✓
Both roots satisfy the original equation.
5

Combining Skills: A Leading Coefficient Other Than One

When the leading coefficient is not 1, factor by decomposition first (Lesson 7), then use the zero product property exactly as before. The solutions may be fractions, and that is perfectly normal.

Example 5

Decomposition, then split

Solve 2x^2+5x=3 by factoring, then check both solutions in the original equation.

Solve:
2x^2+5x-3=0
ac=-6, sum 5: 6 and -1
2x^2+6x-x-3=2x(x+3)-1(x+3)
(x+3)(2x-1)=0
\boldsymbol{x=-3} or 2x-1=0\Rightarrow \boldsymbol{x=\tfrac12}
Check:
x=-3: 2(9)+5(-3)=18-15=3 ✓
x=\tfrac12: 2\left(\tfrac14\right)+5\left(\tfrac12\right)=\tfrac12+\tfrac52=3 ✓
✓

Key ideas

Zero product property: if A\cdot B=0, then A=0 or B=0. So (x-3)(x+5)=0 gives x=3 or x=-5. A number in front gives no solution.
Four steps: make one side 0, factor completely, set each factor = 0, solve each one. A quadratic usually has two solutions (roots).
It must be 0. Rearrange first: x^2+5x=14\to x^2+5x-14=0. Never divide both sides by x: factor it out, and keep x=0.
Check each root in the original equation, with brackets around negatives. When a\neq1, use decomposition; fraction answers like x=\tfrac12 are normal.
