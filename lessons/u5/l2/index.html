Growing Patterns and Types of Variables

Some patterns grow by the same amount every step. Today we describe a growing pattern three ways: in words, in a table of values, and as points on a grid. We also sort the two quantities into the one you choose (independent) and the one that results (dependent).

I can…
  • continue a growing pattern and describe in words how it grows
  • complete and extend a table of values, and find the constant amount it grows by
  • name the independent and the dependent variable in a situation
  • plot a table of values as ordered pairs and say whether the points line up

Growing Patterns

A growing pattern is a sequence of figures or numbers in which each step grows by the same fixed amount every time. We say the pattern grows by a constant amount.

Toothpick Street grows by a constant amount: every new house adds 5 toothpicks. Counting them in groups shows why.

Example 1

A tile pattern

The pattern below is built from small square tiles arranged in two rows. Look for what each new figure adds.

(a) Draw Figure 4 and Figure 5 of the pattern in the space below.
Add one more column of 2 tiles each time.
(b) How many tiles would be in Figure 6? (Continue the pattern.)
Figure 6 has 6 columns of 2 tiles: 6\times2=\boldsymbol{12} tiles. (Or continue 2, 4, 6, 8, 10, 12.)
(c) Describe in words how this pattern grows from one figure to the next.
Each new figure adds one more column of 2 tiles, so the number of tiles goes up by 2 every time: a constant amount.

Watch the tile pattern grow

Each new figure is the one before it plus one new column. Watch the new tiles, and keep a running count.

Representing a Pattern in a Table of Values

A table of values stores the figure number in one row and the resulting value in the other. It makes the pattern easy to read, extend, and later plot.
Figure Number, n123
Number of Tiles, T246

For the tile pattern: n=1,\ 2,\ 3 gives T=2,\ 4,\ 6. The difference between neighbours is the constant amount the pattern grows by.

3

Independent and Dependent Variables

The independent variable is the one you choose. It goes in the first row of a table and on the horizontal (x) axis.
The dependent variable results from that choice: it depends on it. It goes in the second row and on the vertical (y) axis.

If notebooks cost $2 each, the number you buy is the independent variable (you choose it) and the total cost is the dependent variable (it results from your choice). For the tiles, the figure number n is independent and the number of tiles T is dependent.

?
A quick test: say the sentence “___ depends on ___” both ways. Only one way makes sense. The cost depends on the number of notebooks, but the number of notebooks does not depend on the cost (you decide it).

Look for the words “based on”

In a sentence like “the cost, based on the number of kilometres”, the quantity after “based on” is what changes first: the independent variable. The quantity that is “based on” it is the dependent variable.

Example 3

Independent or dependent?

For each situation, identify the independent variable and the dependent variable.

(a) The temperature of an oven while it preheats, based on the number of minutes since it was turned on.
Independent: time in minutes
Dependent: oven temperature
You can choose how many minutes to wait; the temperature results.
(b) The distance a cyclist has travelled, based on the number of hours cycling at a steady speed.
Independent: hours cycling
Dependent: distance travelled
The distance depends on how long the cyclist rides.
(c) The height remaining on a candle, based on the number of hours it has been burning.
Independent: hours burning
Dependent: candle height
The height left depends on how long it has burned.
(d) The total cost of a taxi ride, based on the number of kilometres travelled.
Independent: kilometres travelled
Dependent: total cost
The cost depends on how far you ride.

Plotting a Pattern’s Table of Values

Each column of a table of values is an ordered pair in disguise. The independent value becomes the x-coordinate and the dependent value becomes the y-coordinate. Because these values are positive whole numbers, only Quadrant I is needed. When a pattern grows by a constant amount, its points line up in a straight line. We call it a linear pattern.

!
Count the grid lines carefully. On the Example 4 grid, each line up is 2 tiles, not 1. Read the numbers on the axis before you plot.

Key ideas

Growing pattern: each step grows by the same amount (a constant amount). Say it in words: “starts at 5 and adds 4 each time.”
Table of values: figure number on top, the value underneath. The difference between neighbours is the constant amount: 2,\ 4,\ 6,\ 8 grows by 2.
Independent = you choose it (first row, x-axis). Dependent = it results (second row, y-axis). “Cost, based on kilometres”: kilometres is independent.
Plotting: each column (n,\ T) is a point in Quadrant I. A pattern that grows by a constant amount makes points that line up in a straight row.
