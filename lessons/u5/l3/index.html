Describing Relationships Between Two Quantities

Hours slept and alertness. Pizza size and price. When two quantities are connected, we can write the connection as ordered pairs: (\text{input},\ \text{output}). That list of pairs is called a relation, and we can draw it four ways: as a list, a table, a mapping diagram and a graph. Same pairs, different pictures.

I can…
  • write a relation as a set of ordered pairs, with the input first and the output second
  • read ordered pairs from a table of values, and fill in a table from ordered pairs
  • draw a mapping diagram with arrows from each input to its output
  • plot ordered pairs as points on a graph
  • go from any one picture of a relation to another, and explain why they all show the same relation

What Is a Relation?

A relation is a set of ordered pairs connecting the inputs of one quantity to the outputs of another.

Hours slept and alertness, pizza size and price, pages read and time spent: each is a relation. Each ordered pair (x,\ y) matches one input x with its output y, so the list of ordered pairs is the relation in its most basic form.

(3,6)
input comes first
the independent variable: you choose it
output comes second
the dependent variable: it follows
!
Curly brackets hold the whole set. Write the relation as \{(1,\ 4),\ (2,\ 7),\ (3,\ 10)\}: round brackets around each pair, commas between the pairs, and curly brackets \{\ \} around the whole list.
Example 1

Juice boxes

A vending machine sells juice boxes for $2 each. Let n be the number bought and C the total cost, in dollars.

(a) Determine the total cost for n=1,\ 2,\ 3, and 4 juice boxes.
C=2n: each box adds $2.
n=1\to\$2; n=2\to\$4; n=3\to\$6; n=4\to\$8
(b) Write this relation as a set of ordered pairs (n,\ C).
\{(1,\ 2),\ (2,\ 4),\ (3,\ 6),\ (4,\ 8)\}
Input first, output second.

Representing a Relation with a Table of Values

A table of values is an organized way of writing the ordered pairs: inputs in one row, each matching output directly beside it. Reading straight down a column gives you one ordered pair.
The input row is on top (or the left column, when the table stands up). Each column is one pair: this table holds \{(1,\ 5),\ (2,\ 10),\ (3,\ 15)\}.
Example 2

Tricycle wheels

Each tricycle in a bike-shop display has 3 wheels. The table shows tricycles, t, and total wheels, W.

(a) Write this relation as a set of ordered pairs (t,\ W).
Read straight down each column:
\{(1,\ 3),\ (2,\ 6),\ (3,\ 9),\ (4,\ 12)\}
(b) State the independent variable and the dependent variable.
Independent: t, the number of tricycles (you choose it).
Dependent: W, the total wheels. It follows: three per tricycle.
3

Representing a Relation with a Mapping Diagram

A mapping diagram shows a relation with two ovals joined by arrows: inputs in the left oval, outputs in the right oval. The arrows always point from the input to the output: the same “independent to dependent” direction you already know.
!
Each value goes in its oval once. If two inputs share an output, write that output once and let two arrows point to it. Then count the arrows: one arrow for every ordered pair.

Tangled arrows? Same relation.

The order of the numbers inside an oval doesn’t matter. Read each arrow as an ordered pair. If the pairs match, the diagrams show the same relation, even when the arrows cross (like Jo’s in the warm-up).

Example 3

Chair legs

Each chair at a banquet table has 4 legs. The table shows chairs, c, and total legs, L.

(a) Write this relation as a set of ordered pairs (c,\ L).
\{(2,\ 8),\ (3,\ 12),\ (4,\ 16),\ (5,\ 20)\}
Each chair adds 4 legs, so L=4c.
(b) Represent the relation with the mapping diagram: write the inputs in the left oval and the outputs in the right oval, then draw an arrow from each input to its matching output.
Inputs 2,\ 3,\ 4,\ 5 in the left oval, outputs 8,\ 12,\ 16,\ 20 in the right, each arrow running from an input to its own output.
Think In the warm-up, Ava had two arrows (to the cat and to the fish). Is an input with two arrows allowed in a relation?
Yes. A relation is any set of ordered pairs, and (Ava, cat) and (Ava, fish) are two different pairs. Hold on to this idea: in Lesson 8 you will meet relations where every input has only one arrow.
4

Representing a Relation with a Graph

A relation can also be pictured as a graph. Each ordered pair (x,\ y) becomes one point: the input is measured along the horizontal x-axis and the output along the vertical y-axis. Independent horizontal, dependent vertical, exactly as before.
1Start at the origin (0,\ 0).
2Go right by the input.
3Go up by the output, and draw a dot.

Order matters: (2,\ 5) is not (5,\ 2)

Swap the two numbers and you land on a different point. In a story the meaning changes too: “2 boxes cost $5” is not the same as “5 boxes cost $2”. Always write the input first.

Example 4

From pairs to a table and a graph

Consider the relation given by the ordered pairs (x,\ y): (1,\ 5),\ (2,\ 7),\ (3,\ 9),\ (4,\ 11).

(a) Complete the table of values.   (b) Plot the four ordered pairs on the grid.
(a) The outputs are 5,\ 7,\ 9,\ 11.  (b) Points at (1,\ 5),\ (2,\ 7),\ (3,\ 9),\ (4,\ 11): each step of 1 to the right raises y by 2.

Same Relation, Three Pictures

A table of values, a mapping diagram and a graph can all describe the exact same relation. They are three pictures of one set of ordered pairs. Find the ordered pairs, and you can build any one picture from any other.
Ordered pairs\{(1,\ 4),\ (2,\ 6),\ (3,\ 8)\}
Tableeach column is a pair
Mapping diagrameach arrow is a pair
Grapheach point is a pair

Spot the mismatch

Four pictures that are supposed to show the same relation. One of them has a mistake. Check each picture against the ordered pairs, one pair at a time.

Example 5

One relation, three pictures

The mapping diagram below shows a relation between two sets of numbers, A and B.

(a) Write this relation as a set of ordered pairs (A,\ B).
Follow each arrow:
\{(2,\ 5),\ (4,\ 9),\ (6,\ 13),\ (8,\ 17)\}
(b) Complete a table of values for this relation.
A: 2,\ 4,\ 6,\ 8   B: 5,\ 9,\ 13,\ 17
(c) Plot the ordered pairs from part (a) on the grid to represent this relation as a graph.
Four points: (2,\ 5),\ (4,\ 9),\ (6,\ 13),\ (8,\ 17). Each time A goes up by 2, B goes up by 4, so the points climb steadily.
(d) In one sentence, explain why the mapping diagram, the table, and the graph all describe the same relation.
All three are built from the very same four ordered pairs: the diagram shows them as arrows, the table as columns and the graph as points, so they carry the same information in three different formats.
✓

Key ideas

A relation is a set of ordered pairs (\text{input},\ \text{output}). Input first: (2,\ 5) and (5,\ 2) are different pairs.
Table of values: inputs in the top row (or left column). Read straight down a column to get one ordered pair.
Mapping diagram: inputs in the left oval, outputs in the right. Arrows point from input to output. The order inside an oval doesn’t matter.
Graph: go right by the input, up by the output: one point per pair. Pairs, table, diagram and graph are all the same relation.
