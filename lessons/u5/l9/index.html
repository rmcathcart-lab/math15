Function Notation: Evaluating and Interpreting f(x)

In Lesson 8 you learned to spot a function: every input has exactly one output. Today we give a function a name and a short way to write “the output when the input is x”: f(x), read “f of x”. Then we put numbers, letters and expressions in, and read what comes out.

I can…
  • read f(3)=11 as “f of 3 is 11”: the name is f, the input is 3, the output is 11 (and it is not f times 3)
  • rewrite y=2x+5 as f(x)=2x+5
  • evaluate f(a) by putting the input into every x, in brackets, including negative numbers
  • evaluate a function for a letter or an expression, such as f(k) or f(x+1)
  • explain what a statement like C(4)=18 means in a real situation, and write a sentence in function notation

1

Introducing Function Notation

When a relation is a function (every input has exactly one output), we may rename y with a more descriptive label: f(x), read “f of x.” The equations y=2x+5 and f(x)=2x+5 say exactly the same thing, but f(x) shows which function made the output and which input was used.

!
Warning: f(x) does not mean “f times x”. The brackets hold an input, not a multiplication.
xinput
function f
f(x)output

f is a machine: the input x goes in, the rule is applied, and the output f(x) comes out.

Name, input, output

The letter out front (f,\ g,\ h,\ C,\ \ldots) is just the function’s name. x is the input (independent variable) and f(x) is the output (dependent variable): the job y always did.

y= notation
function notation
y=2x+5
f(x)=2x+5
When x=3: y=2(3)+5
f(3)=2(3)+5
y=11
f(3)=11
input 3, output 11: the point (3,\ 11)

Math History1673 · 1734

Who first wrote f(x)?

In 1673 the German mathematician Gottfried Leibniz started using the word “function”. He had no short way to write one.

In 1734 the Swiss mathematician Leonhard Euler (say “OY-ler”) wrote \color{#7b4fc4}f\color{#3d2817}\left(\color{#1f5bd6}\tfrac{x}{a}+c\color{#3d2817}\right): f for function, the input in brackets. It is the same notation you write today.

Euler’s inputs were often expressions. For f(x)=2x+5, find f\left(\tfrac{8}{2}+1\right).
Work out the input first: \tfrac{8}{2}+1=5. Then f(5)=2(5)+5=\boldsymbol{15}.
2

Evaluating a Function for a Given Input

To evaluate f(a), replace every x in the formula with a, then simplify using the order of operations.

Every x in the rule is a slot. The input goes into every slot, in brackets.

!
Brackets around a negative input. For g(x)=x^2+3, g(-1)=(-1)^2+3=1+3=4. A negative number squared is positive. Without brackets, -1^2 means -(1^2)=-1, and you would get 2, which is wrong.
Example 1

One function, four inputs

Consider the function f(x)=2x+5. Evaluate each of the following.

(a) f(3)
f(3)=2(3)+5
=6+5
=\boldsymbol{11}
(b) f(0)
f(0)=2(0)+5
=0+5
=\boldsymbol{5}
(c) f(-4)
f(-4)=2(-4)+5
=-8+5
=\boldsymbol{-3}
(d) f(6)
f(6)=2(6)+5
=12+5
=\boldsymbol{17}
Part (c) on the TI-30XIIS. Use the negative key (−) for −4, not the minus key: 2×(−)4+5ENTER gives −3.
Example 2

Two functions, five values

Consider the functions f(x)=5x-4 and g(x)=x^2+3. Evaluate each of the following.

(a) f(3)
f(3)=5(3)-4
=15-4=\boldsymbol{11}
(b) g(3)
g(3)=(3)^2+3
=9+3=\boldsymbol{12}
(c) f(-2)
f(-2)=5(-2)-4
=-10-4=\boldsymbol{-14}
(d) g(-1)
g(-1)=(-1)^2+3
=1+3=\boldsymbol{4}
(a negative squared is positive)
(e) f(0)+g(0)
f(0)=5(0)-4=-4   and   g(0)=(0)^2+3=3
f(0)+g(0)=-4+3=\boldsymbol{-1}
Part (d) on the calculator. Bracket the negative: ((−)1)x²+3ENTER gives 4. Leave the brackets out and the calculator squares only the 1: it gives 2.

Read the direction carefully

f(3) hands you the input (3) and asks for the output. Go forwards through the rule.
f(x)=11 hands you the output (11) and asks which input made it. Go backwards.
3

Evaluating for a Variable or Expression Input

The same substitution works when the input is not a plain number. To find f(a), f(k) or f(x+1), replace every x with whatever sits inside the brackets, then simplify.

When the input is an expression, wrap it in brackets everywhere it lands, so nothing gets lost while you simplify.
Example 3

Letters and an expression into a linear function

Consider the function f(x)=3x+2. Determine each of the following.

(a) f(a)
Replace every x with a:
f(a)=3(a)+2
=\boldsymbol{3a+2}
(b) f(k)
The letter does not matter, only the position does:
f(k)=3(k)+2=\boldsymbol{3k+2}
(c) f(x+1)
Put the whole expression in brackets:
f(x+1)=3(x+1)+2
=3x+3+2=\boldsymbol{3x+5}
Example 4

Letters and an expression into a squared function

Consider the function f(x)=x^2+4. Determine each of the following.

(a) f(a)
f(a)=(a)^2+4
=\boldsymbol{a^2+4}
(b) f(2a)
f(2a)=(2a)^2+4
=(2a)(2a)+4
=\boldsymbol{4a^2+4}
The brackets matter: the 2 is squared too, so it is 4a^2, not 2a^2.
(c) f(x+3)
Hint: first expand (x+3)^2.
f(x+3)=(x+3)^2+4
(x+3)^2=x^2+3x+3x+9=x^2+6x+9
So f(x+3)=x^2+6x+9+4
=\boldsymbol{x^2+6x+13}

Check Example 4: the square takes the whole input

The input goes into the slot whole and in brackets, so the square acts on all of it. Then check your answer by putting a number in for the letter: both forms must agree.

4

Interpreting Function Notation in Context

If C(n) is the total cost, in dollars, of buying n items, then C(5)=23 is shorthand for “buying 5 items costs $23.” The translation runs both ways: “the cost of 8 items is $35” becomes C(8)=35.

\textcolor{#7b4fc4}{C}(\textcolor{#1f5bd6}{5})=\textcolor{#c27a0e}{23}⇄“buying 5 items costs $23”
\textcolor{#7b4fc4}{C}(\textcolor{#1f5bd6}{8})=\textcolor{#c27a0e}{35}⇄“the cost of 8 items is $35”

The number inside the brackets is the input: what you choose. The number after the equals sign is the output: what you get.

Example 5

The taco truck

A food truck charges a flat $6 setup fee for a catering order, plus $3 per taco. The total cost, in dollars, of ordering n tacos is C(n)=3n+6.

(a) Evaluate C(4). Then explain, in words, what this value represents in this situation.
C(4)=3(4)+6=12+6=\boldsymbol{18}
Meaning: ordering 4 tacos costs $18 (the $6 setup fee plus $12 of tacos).
(b) The statement C(10)=36 is true for this function. Explain, in words, what this statement means in this situation.
The input 10 is a number of tacos and the output 36 is a cost in dollars, so: ordering 10 tacos costs $36.
(Check: 3(10)+6=36 ✓)
(c) Translate into a function notation statement, and check that it is correct: “The cost of ordering 12 tacos is $42.”
Input = 12 tacos, output = $42: \boldsymbol{C(12)=42}
Check: C(12)=3(12)+6=36+6=42 ✓
The statement is correct.
Think D(t) is the distance, in kilometres, a cyclist rides in t hours. Which sentence matches D(2)=30?
The cyclist rides 2 km in 30 hours.
The cyclist rides 2 km every hour.
In 2 hours the cyclist rides 30 km.

C. Inside the brackets is the input: 2 hours. After the equals sign is the output: 30 km. A swaps them.
✓

Key ideas

Read it: f(3)=11 is “f of 3 is 11”: name f, input 3, output 11. It is not f times 3. f(x) does the job y used to do.
Evaluate: put the input into every x, in brackets, then use the order of operations: f(-4)=2(-4)+5=-3; g(-1)=(-1)^2+3=4.
Letters and expressions go in the same way, whole and in brackets: f(x+1)=3(x+1)+2=3x+5; f(2a)=(2a)^2+4=4a^2+4.
In context: inside the brackets is the input, after the equals sign is the output. C(4)=18: ordering 4 tacos costs $18.
