Domain and Range of a Relation, Part 1: Reading From a Graph

Shine a light on a graph and it casts two shadows: one on the floor (the x-axis) and one on the wall (the y-axis). Today we read them. The domain is how far the graph reaches from left to right. The range is how far it reaches from bottom to top.

I can…
  • read the domain of a graph: every x-value from the leftmost point to the rightmost point
  • read the range of a graph: every y-value from the lowest point to the highest point
  • tell a discrete graph (separate dots: write a list) from a continuous graph (unbroken: “from … to …”)
  • scan the whole graph, because the highest or lowest point is not always at an end
  • keep only the values that make sense in a real situation, like a time that can’t be negative

1

Domain: How Far the Graph Reaches Left to Right

The domain of a relation is the set of all possible x-values: the inputs the relation uses.

To read it from a graph, find the graph’s leftmost point and its rightmost point. The domain is every x-value from one to the other. The graph at left starts at x=-4 and ends at x=3, and every x-value in between is used somewhere on the line. So its domain is: x can be any value from -4 to 3.

Example 1

The domain of a line segment

The graph below shows a line segment.

(a) State the domain of the graph.
The segment starts at x=-2 (leftmost point) and ends at x=4 (rightmost point), unbroken in between.
Domain: x can be any value from -2 to 4.
(b) Could x=5 be part of this relation? Explain.
No. The graph stops at the endpoint (4,1), so no point on it has x=5. The value 5 is outside the domain.
2

Range: How Far the Graph Reaches Bottom to Top

The range of a relation is the set of all possible y-values: the outputs the relation produces.

To read it from a graph, find the graph’s lowest point and its highest point. The range is every y-value from one to the other. The lowest point at left is y=-1 and the highest is the peak at y=4. So the range is: y can be any value from -1 to 4.

Example 2

The range of a curve

The graph below shows a curve.

(a) State the range of the graph.
Scan the curve from bottom to top: the lowest point is (0,-3) and the highest point is the right endpoint (3,4).
Range: y can be any value from -3 to 4.
(b) Could y=5 be part of this relation? Explain.
No. The highest the curve ever reaches is y=4, so no point on the graph has a y-value of 5.
3

Discrete Graphs vs. Continuous Graphs

Discrete A set of separate dots that are not joined. Only the plotted points belong to the relation, so write the domain and range as a list of the exact values used: “x can be -3, 0 or 4.”
Continuous An unbroken line or curve with no gaps. Every point along it counts, so describe the domain and range as everything from the lowest value to the highest value.

Example 3

Discrete or continuous?

For each graph, state whether it is discrete or continuous, then state its domain and range.

(a)
Type: discrete. Separate dots, so list each value.
D: -4,\ -2,\ 0,\ 1,\ 3
R: -1,\ 0,\ 1,\ 3,\ 4
(b)
Type: continuous. An unbroken segment, so give the endpoints.
D: x from -3 to 4
R: y from -2 to 3
i
Reminder. A discrete answer is a list of the dots’ values. A continuous answer runs “from to .” Count squares carefully before writing each endpoint.
Think If you joined the dots in (a) from left to right, what would the domain and range become?
The graph would be continuous, so the lists turn into “from … to …”: x from -4 to 3, and y from -1 to 4. Now every value in between counts, like x=2.5.
4

Curves That Bend More Than Once

On a curve that bends more than once, the highest or lowest point is not always at one of the two endpoints. Always scan the whole graph, not just its ends, before you state the domain and range.

!
The ends can fool you. The domain always comes from the leftmost and rightmost points. But for the range, look for the peaks and dips too: the highest or lowest point may be in the middle.
Example 4

Scan the whole curve

The graph below shows a continuous curve.

(a) State the domain of the graph.
Leftmost point x=-4, rightmost point x=4, unbroken in between.
Domain: x from -4 to 4.
(b) State the range of the graph. (Hint: look at the whole curve, not just the two ends.)
The lowest point is an endpoint: y=-3 at (-4,-3). But the highest point is not an endpoint: the curve peaks at (0,2). (The right endpoint only reaches y=-2.)
Range: y from -3 to 2.
5

Domain and Range in Everyday Graphs

When a graph tells the story of a real situation, the domain and range only include values that make sense. On a height-versus-time graph, time cannot be negative: the situation only exists once it begins. Always ask what is happening in real life before you write the domain and range.

Example 5

A toy rocket

A toy rocket is launched straight up from the ground. The graph shows the rocket’s height, h metres, after t seconds. It peaks at 20 m when t=3 s and lands at t=6 s.

(a) State the domain of the graph (in seconds).
The flight starts at t=0 (launch) and ends at t=6 (landing).
Domain: t from 0 to 6 seconds.
(b) State the range of the graph (in metres).
Lowest height 0 m (on the ground at the start and the end); highest height 20 m at the peak.
Range: h from 0 to 20 metres.
(c) Explain why the domain of this graph could not include negative values of t.
A negative t would mean “before the rocket was launched.” The situation only exists from the moment of launch onward, so time starts at 0 and no negative t-values make sense.

Putting it together

Every question today came down to the same few checks. Dots or unbroken? Leftmost to rightmost? Lowest to highest, scanning the whole graph? And in a real situation: does it make sense?

✓

Key ideas

Domain = the floor shadow: all the x-values, from the leftmost point to the rightmost point. Range = the wall shadow: all the y-values, from the lowest point to the highest point.
Discrete (separate dots): write a list, each value once, like D: -4,\ -2,\ 0,\ 1,\ 3. Continuous (unbroken): write “from … to …”, like x from -3 to 4.
Scan the whole graph. The highest or lowest point can be a peak or a dip in the middle. Example 4: y from -3 to 2, and the peak is not an end.
Real situations: keep only values that make sense. Time can’t be negative. The rocket: t from 0 to 6 s, h from 0 to 20 m.
