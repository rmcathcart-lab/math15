Unit Review: Relations and Functions

The whole unit in one lesson: one reminder and one review question for every idea, then three mixed challenges like the ones on the test. One big idea ties it together: a relation is a set of ordered pairs you can show four ways, and a function gives every input exactly one output.

I can…
  • plot points and name the quadrant (or axis) of any point
  • extend a pattern, and name the independent and dependent variables
  • show one relation as ordered pairs, a table, a mapping diagram and a graph
  • find intercepts and the domain and range, from a table, a graph, a list or a calculator screen
  • use the vertical line test, and use function notation forwards and backwards
  • read and sketch real-world graphs
RF1 Interpret and explain the relationships among data, graphs and situations.
RF2 Demonstrate an understanding of relations and functions.
RF4 Describe and represent linear relations, using words, ordered pairs, tables of values, graphs and equations.
RF5 Determine the characteristics of the graphs of linear relations, including the intercepts, slope, domain and range.
RF8 Represent a linear function, using function notation.

1

The Cartesian Plane and Plotting Points

The signs of the coordinates decide the quadrant. A zero coordinate puts a point on an axis, not in a quadrant.

Example 1

Quadrants, then plotting

(a) State the quadrant (or axis) containing each point.
P(-6,\ 2)Quadrant II
Q(4,\ -5)Quadrant IV
R(0,\ 7)on the y-axis
S(-3,\ -8)Quadrant III
P is (-,+): II. Q is (+,-): IV. x=0 puts R on the vertical axis (no quadrant). S is (-,-): III.
(b) Plot and label T(3,\ 5), U(-4,\ 1), V(-2,\ -6) and W(5,\ -3).
Run across first, then up or down. T: right 3, up 5 (I). U: left 4, up 1 (II). V: left 2, down 6 (III). W: right 5, down 3 (IV).
2

Patterns and Variables

A growing pattern adds the same amount each step. The variable you control is the independent variable; the one that results is the dependent variable.

Example 2

Rows of chairs

A community centre sets up rows of chairs. Row 1 has 6 chairs, and each row after has 5 more than the row before.

(a) Complete the table of values for Rows 1 to 5.
Row Number, n12345
Chairs, C611162126
Add 5 each row: 6,\ 11,\ 16,\ 21,\ 26. (Rule: C=5n+1.)
(b) State the independent variable and the dependent variable.
Independent: the row number n: you choose which row to look at.
Dependent: the number of chairs C: it is decided by the row number.
3

Representing a Relation

Ordered pairs, a table, a mapping diagram and a graph are four pictures of the same set of pairs.

Example 3

From a mapping diagram

The mapping diagram shows a relation between sets A and B.

(a) Write this relation as a set of ordered pairs (A,\ B).
Follow each arrow, input first: \boldsymbol{(10,\ 2),\ (20,\ 4),\ (30,\ 6),\ (40,\ 8)}
(b) Represent the same relation in a table of values.
A10203040
B2468
Same relation, different picture: each output is \tfrac15 of its input.

4

Intercepts

An x-intercept has y=0 (it is on the x-axis). A y-intercept has x=0 (it is on the y-axis).

Example 4

Intercepts from a table

The table shows several points on a relation.

x-101234
y-4-3-2-101
(a) Which ordered pair is the y-intercept?
Find the column with x=0; it pairs with y=-3: \boldsymbol{(0,\ -3)}
(b) Which ordered pair is the x-intercept?
Find the column with y=0; it pairs with x=3: \boldsymbol{(3,\ 0)}
5

Domain and Range

Domain = all the x-values. Range = all the y-values. Read them off a graph (squash it onto each axis), or list them in set notation.

Example 5

A segment, then a list

State the domain and range for each relation.

(a) The graph shows a line segment. State its domain and range.
The endpoints are (-5,\ -3) and (3,\ 6), and the segment is unbroken between them.
D:\ -5\le x\le 3\qquad R:\ -3\le y\le 6
(b) State the domain and range, using set notation, of the relation (3,\ 7),\ (5,\ 2),\ (3,\ 9),\ (8,\ 2).
x’s: 3,5,3,8: the 3 is written once. y’s: 7,2,9,2: the 2 is written once.
D=\{3,\ 5,\ 8\}\qquad R=\{2,\ 7,\ 9\}

Example 5 check: squash it onto the axes

6

Using Technology to Graph a Relation

A graphing calculator draws the relation once you enter it and set a window. A line that runs off both edges without turning has a domain and range of all real numbers.

Example 6

Diego’s calculator screen

Diego graphs y=-2x+8 in the standard window, x:[-10,\ 10], y:[-10,\ 10].

(a) State the window shown on the screen.
The standard window: x:[-10,\ 10], y:[-10,\ 10].
(b) Use the screen to estimate the x-intercept and the y-intercept.
The line meets the y-axis at 8 and the x-axis at 4: y-intercept \boldsymbol{(0,\ 8)}, x-intercept \boldsymbol{(4,\ 0)}. Check: y=-2(0)+8=8; 0=-2x+8\Rightarrow x=4 ✓
(c) State the domain and range of this relation.
The line leaves the screen through opposite edges with no endpoints, so it continues forever. Domain: all real numbers. Range: all real numbers.
7

Functions and the Vertical Line Test

A relation is a function when each input has exactly one output: no vertical line may cross the graph twice.

Example 7

Which one is not a function?

Exactly one graph below is not a function. Use the vertical line test to identify it, and justify your answer.

Graph B is not a function. A vertical line through the middle of the circle (for example x=0) crosses it twice, once at the top and once at the bottom: one input has two different outputs. A (an arch) and C (a V) each pass the test: every vertical line meets them at most once.
8

Evaluating Function Notation

To find f(a), substitute a for every x (forwards). To work backwards, set the rule equal to the output and solve.

Example 8

Forwards, then backwards

Consider the function g(x)=4x-9.

(a) Determine the value of g(6).
Substitute the input:
g(6)=4(6)-9=24-9=\boldsymbol{15}
(b) If g(k)=7, determine the value of k.
The output is given, so set the rule equal to 7 and solve:
4k-9=7\ \Rightarrow\ 4k=16\ \Rightarrow\ k=\boldsymbol{4}
Check: g(4)=4(4)-9=7 ✓
9

Function Notation with Graphs and Models

Function notation can be read off a graph, or used to model a real cost that depends on a quantity n.

Example 9

From a graph, and from a model

(a) The diagram shows the graph of y=f(x). Use it to determine the value of f(-1)+f(2).
At x=-1 the point is (-1,\ 0), so f(-1)=0. At x=2 the point is (2,\ -6), so f(2)=-6.
f(-1)+f(2)=0+(-6)=\boldsymbol{-6}
(b) A dog-walking business charges a $10 booking fee plus $8 for each walk, so the cost of n walks is W(n)=10+8n. Determine W(5), and state the domain of this relation.
W(5)=10+8(5)=10+40=\boldsymbol{\$50}: five walks cost $50.
A number of walks is a whole number and cannot be negative, so the domain is \boldsymbol{\{0,\ 1,\ 2,\ 3,\ \dots\}} (also written n\ge 0, n a whole number).
Order of operations is built in. For W(5), type the rule as it is written: 10+8×5= gives 50 (it multiplies first). For a negative input like g(-2)=4(-2)-9, use the (−) key: 4×(−)2−9= gives -17.

Example 9 check: across, up or down, then over

10

Interpreting and Sketching Real-World Graphs

Rising means increasing, falling means decreasing, flat means staying the same. No numbers are needed to sketch: only the shape.

Example 10

Read one graph, sketch the other

(a) The graph shows a cyclist’s speed, in km/h, during the first 7 minutes of a ride. Describe, in words, what happens to the speed during the first 2 minutes, during minutes 2 through 5, and during the last 2 minutes.
Minutes 0–2: the graph rises from 0 to about 15 km/h: the cyclist starts from rest and speeds up steadily.
Minutes 2–5: flat at about 15 km/h: the speed is constant (cruising).
Minutes 5–7: the graph falls back to 0: the cyclist slows down steadily and stops.
(b) Sketch a graph showing the temperature of a cup of hot coffee, from the moment it is poured until it has cooled down to room temperature and stays there.
Start high (just poured), fall steeply at first, then flatten as the coffee nears room temperature. Once it gets there the graph is flat: it cannot cool any further.

Mixed Review: Putting It All Together

Each question below combines more than one skill: exactly like a test question. (Check them with the Challenge chips in the explainers of Sections 3, 4, 5, 7 and 8.)

Challenge 1

The landscaping company

A landscaping company charges a $25 site fee plus $15 per tree planted: C(p)=25+15p.

(a) Determine C(8).
C(8)=25+15(8)
=25+120=\boldsymbol{\$145}
(b) If C(p)=175, determine the number of trees planted.
25+15p=175
15p=150
p=\boldsymbol{10} trees. Check: 25+15(10)=175 ✓
(c) State an appropriate domain for this function, given the context.
You can’t plant a negative number of trees, or part of a tree: D=\{0,\ 1,\ 2,\ 3,\ \dots\}, the whole numbers. (A sensible upper limit, like the most the crew can plant in a day, is also fine.)
Challenge 2

One graph, three questions

The graph below shows a relation.

(a) Is this relation a function? Justify your answer using the vertical line test.
Yes. The curve opens downward, so any vertical line meets it at most once. Every input has exactly one output.
(b) State the domain and range of the relation.
The curve runs from the solid dot at x=-2 to the solid dot at x=4; its lowest points are those ends (y=0) and its peak is (1,\ 9), so
D:\ -2\le x\le 4\qquad R:\ 0\le y\le 9
(c) State the coordinates of the x-intercepts and the y-intercept.
x-intercepts \boldsymbol{(-2,\ 0)} and \boldsymbol{(4,\ 0)}; y-intercept \boldsymbol{(0,\ 8)}. Check with y=-x^2+2x+8: at x=0, y=8; at x=4, -16+8+8=0; at x=-2, -4-4+8=0 ✓
Challenge 3

The community garden

A community garden has 8 plants in Week 1, and 6 more plants are added every week after that. Let n be the week number and P(n) the number of plants.

(a) Write a function rule P(n).
Week 1 has 8; each later week adds 6, so after n-1 extra weeks:
P(n)=8+6(n-1)=8+6n-6=\boldsymbol{6n+2}. Check: P(1)=8 ✓
(b) Determine P(6).
P(6)=6(6)+2=36+2=\boldsymbol{38} plants
(c) In what week will there be 62 plants?
6n+2=62
6n=60
n=\boldsymbol{10}: Week 10
(d) State a reasonable domain, given the context.
Week numbers are counting numbers starting at 1: D=\{1,\ 2,\ 3,\ 4,\ \dots\}. (There is no “week 2.5”.)
✓

Key ideas

A relation is a set of ordered pairs (x,\ y), shown four ways: pairs, table, mapping diagram, graph. Across first, then up or down.
Domain = all x-values, range = all y-values. Intercepts: y=0 for the x-intercept, x=0 for the y-intercept.
Function: each input has exactly one output (vertical line test). f(a): substitute. f(x)=b: solve.
Real-world graphs: rising, falling, flat; steep = fast. Read the axis labels, and think about the context for the domain.
