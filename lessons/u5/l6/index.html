Recall: Domain and Range from a Graph

The domain is the complete set of input (x) values a relation uses. The range is the complete set of output (y) values it produces. On a graph we found these by shining an imaginary light down (domain) or across (range). Today the relation arrives already written as ordered pairs or in a table, so we read the values directly instead.

2

Domain and Range from a Set of Ordered Pairs

Every ordered pair has the form (x,y). The domain is every x-coordinate that appears. The range is every y-coordinate that appears. A repeated value is written only once.

For (2,5),\ (3,5),\ (4,8),\ (6,1) the x’s are 2,\ 3,\ 4,\ 6 (no repeats), so the domain is 2,\ 3,\ 4,\ 6. The y’s are 5,\ 5,\ 8,\ 1; the 5 repeats, so the range is 1,\ 5,\ 8. List the values from smallest to largest: it makes repeats easy to spot.

The warm-up machine is a relation

Each working button and its snack make a pair: (button, snack), like (A1, Chips). The buttons are the inputs and the snacks are the outputs, so the same rules apply.

Example 1

Ordered pairs

List the domain and range of each set of ordered pairs.

(a) (1,4),\ (2,6),\ (3,4),\ (5,9)
x’s: 1,\ 2,\ 3,\ 5: no repeats.
y’s: 4,\ 6,\ 4,\ 9: the 4 repeats, so write it once.
Domain: 1,\ 2,\ 3,\ 5   Range: 4,\ 6,\ 9
(b) (7,2),\ (7,5),\ (7,8)
x’s: 7,\ 7,\ 7: all the same, so the domain has just one value.
y’s: 2,\ 5,\ 8: all different.
Domain: 7   Range: 2,\ 5,\ 8

Domain and Range from a Table of Values

A table lists the same information as a set of ordered pairs, just organized into two rows instead of brackets. The same rule applies: the domain is every value in the x-row and the range is every value in the y-row, each written once.

Example 2

State the domain and range of each relation given by a table of values.

(a)
Read straight off the rows (no repeats in either).

Range: 2,\ 4,\ 6,\ 8,\ 10
(b)
The y-row is 5,\ 2,\ 5,\ 2: only two different values, each written once.
Domain: -3,\ -1,\ 1,\ 3
Range: 2,\ 5

Formal Set Notation for Domain and Range

Mathematicians write these lists inside curly braces \{\ \ \} to show they form a set: a collection of values with no repeats. The demonstration in Section 2 becomes D=\{2,\ 3,\ 4,\ 6\} and R=\{1,\ 5,\ 8\}.

When a list is impossible

Some relations have infinitely many values. They can’t be listed, so we describe them with an inequality instead. An arrow on the end of a graph means it keeps going forever: a ray that starts at (2,1) and rises forever up and to the right has every y-value 1 or greater, so its range is y\ge 1. A continuous piece with solid dots at both ends works the same way: “x from -3 to 4” (Lesson 5) is written -3\le x\le 4.

A list a few separate values (dots, pairs, a table): D=\{2,\ 4,\ 6\}
An inequality a continuous or unending relation (no gaps, or an arrow): x\ge 0, -3\le x\le 4
!
Read the symbol out loud. \ge is “greater than or equal to” and \le is “less than or equal to”. “0 or greater” is x\ge 0; “6 or less” is x\le 6. The “or equal” part means the starting value itself is included.

A real situation can limit the domain

When a relation comes from real life, the situation itself can set limits: a store may sell only so many, a worker may work only so many hours. An answer that would need more than the limit is not possible, even if the arithmetic works.

Example 5

Deshawn’s part-time job

Deshawn earns $12 per hour at his part-time job. He can work at most 10 hours per week at this job. The table shows his earnings, E dollars, for various numbers of hours worked, h.

(a) State the domain and range of this relation using set notation.
Hours are the inputs, earnings the outputs:
D=\{2,\ 4,\ 6,\ 8,\ 10\}
R=\{24,\ 48,\ 72,\ 96,\ 120\}
(b) Explain why h cannot be greater than 10 in this situation.
Deshawn is allowed to work at most 10 hours per week at this job, so 11 or 12 hours is not possible. The situation itself limits the domain.
(c) Could Deshawn earn $144 in one week at this job? Explain.
No. Earning $144 would take 144\div 12=12 hours, but he can work at most 10 hours, so the most he can earn in a week is 10\times\$12=\$120.
✓

Key ideas

Domain = the inputs: the x-values (the first numbers, or the top row). Range = the outputs: the y-values (the second numbers, or the bottom row).
Each value once. (2,5),\ (3,5),\ (4,8),\ (6,1): the 5 repeats, so the range is 1,\ 5,\ 8. List smallest to largest: repeats are easy to spot.
Set notation: curly braces, no repeats, order doesn’t matter: D=\{2,\ 3,\ 4,\ 6\}, R=\{1,\ 5,\ 8\}. One value is fine: R=\{7\}.
Can’t list it? A ray goes on forever: use an inequality, like x\ge 0. Real situations limit the domain: Deshawn’s h can’t be more than 10, so he can’t earn more than $120.
