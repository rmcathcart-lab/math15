Introducing Functions: The Vertical Line Test

Some relations are well behaved: give them an input and you get back exactly one output, every time. Those relations are called functions. Today we learn to spot one in a mapping diagram, a list of ordered pairs, a table and a graph, where a quick check called the vertical line test does the job.

I can…
  • explain what a function is: every input is paired with exactly one output
  • decide from a mapping diagram by counting the arrows leaving each input
  • decide from ordered pairs or a table by looking for a repeated x-value with a different y-value
  • use the vertical line test on a graph, and write two ordered pairs that show a graph is not a function
  • explain why a real situation is, or is not, a function

1

From Relations to Functions

A relation pairs inputs (the domain) with outputs (the range). It may pair an input with any number of outputs.

A function is a relation in which every input is paired with exactly one output. If even one input is paired with two different outputs, the relation is not a function.
Mapping diagram
Count the arrows leaving each input. Exactly one from every input: function. Two or more from any input: not a function.
Arrows coming in
Arrows pointing into an output never matter. An output may be used as often as you like.
Example 1

Favourite subject and clubs joined

Four students were asked two questions. Diagram A gives each student’s one favourite subject; Diagram B gives every club each student joined.

Diagram A — Favourite Subject
(a) Count the arrows leaving each student. Is this relation a function? Explain.
Arrows leaving: Ana 1, Ben 1, Cho 1, Dev 1.
Yes, it is a function. Every student (input) has exactly one favourite subject. Math is used twice (Ana and Dev), but a repeated output is allowed.
Diagram B — Clubs Joined
(b) Count the arrows leaving each student. Is this relation a function? Explain.
Arrows leaving: Ana 2 (Chess and Track), Ben 1, Cho 1, Dev 1.
No, not a function. Ana, a single input, is paired with two different outputs.

Checking a List of Ordered Pairs or a Table

The one-output rule doesn’t change; only the way you look for it does. Scan the x-values (the inputs).

Not a function
The same x-value appears twice with two different y-values.
Still fine
A repeated y-value is never a problem.
Still fine
The same pair listed twice is not a problem either.

3

The Vertical Line Test

Vertical line test: if any vertical line crosses the graph more than once, the relation is not a function: that line has found one input with two different outputs. If every vertical line crosses at most once, the graph is a function.
The line x=1 meets the graph once: function.
The line x=0 meets the circle twice, at y=2.5 and y=-2.5: not a function.

Why vertical? Every point on a vertical line has the same x-value. So the points the line passes through are all the outputs of that one input.

!
Horizontal lines don’t count. A horizontal line crossing twice means two inputs share one output. That is allowed for a function. Only a vertical line crossing twice breaks the rule.

Sweep the line across

Slide a vertical line from left to right across the whole graph. Watch the number of crossings.

Example 3

Draw your own vertical lines

Draw two or three vertical lines of your own on each grid, then decide: function or not a function?

(a) Function or not? Explain how you know.
Function. Every vertical line I draw (one on each arm of the V, and one right at the corner) crosses the graph exactly once. No input goes to two outputs.
(b) Function or not? Explain how you know.
Not a function. A vertical line at x=-0.4 hits the curve twice, near y=2 and near y=-2. One input, two different outputs. (Every sideways parabola fails for the same reason.)

Classifying Several Graphs at Once

Run the test in your head, left to right across each graph. Some shapes always give the same answer:

Always pass
Straight lines that are not vertical, and ordinary parabolas opening up or down.
Always fail
Closed curves (circles, ellipses, loops), sideways parabolas, and vertical lines.

Functions in Context

Real quantities measured over time are functions: at one instant a thermometer, an odometer or an altimeter can only show one reading. A relation fails when a single input honestly has several outputs (one bus route number, many stops along that route).

Example 5

Temperature over one day

The graph shows the outdoor temperature T (°C) recorded hourly over one day, starting at midnight.

(a) Apply the vertical line test. Is temperature over time a function? Explain.
Yes, it is a function. Pick any time, say t=16 h: the vertical line through it meets the curve just once (at T=14 °C). The graph never doubles back, so no vertical line can cross it twice.
(b) Explain why it makes sense that at one moment in time the outdoor temperature could not be two different values at once.
At one instant the thermometer shows one reading. The same place can’t be 10 °C and 14 °C at the very same moment, so each input (time) has exactly one output (temperature).
(c) Describe a different everyday relation that would not be a function, and explain why in one sentence.
Pairing each month with the students born in it: one input (say September) is paired with several different students, so one input has many outputs. (Other good answers: a jersey number paired with every player who has worn it; a price paired with all the items that cost it.)
✓

Key ideas

Function: a relation in which every input is paired with exactly one output. One input with two different outputs: not a function.
Mapping diagrams: count the arrows leaving each input. Arrows coming into an output never matter.
Pairs and tables: look for the same x with two different y-values. A repeated y, or the same pair twice, is fine.
Graphs: the vertical line test. If any vertical line crosses more than once, it is not a function, and those crossings give the proof, like (0,\ 2.5) and (0,\ -2.5).
