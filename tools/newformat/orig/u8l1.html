What Is a System of Linear Equations? Solving by Graphing

Two equations at once. Each line is full of points that make its own equation true, but only one point is on both lines: the point where they cross. That point is the solution to the system.

I can…
  • explain what a system of linear equations is and what its solution means
  • read the solution off a graph and write it as an ordered pair (x,\ y), x first
  • rewrite an equation like 2x+y=1 in slope-intercept form, y=mx+b
  • graph both lines by hand from the y-intercept and the slope, and find where they cross
  • check a solution by substituting it into both original equations

1

What Is a System of Linear Equations?

The equation y=x+2 is true for many pairs: (0,\ 2), (1,\ 3), (4,\ 6). A second equation, y=-x+6, has many pairs of its own: (0,\ 6), (1,\ 5), (6,\ 0). Only one pair makes both true at once: x=2,\ y=4, since 4=2+2 ✓ and 4=-2+6 ✓.

Two linear equations considered together form a system of linear equations. The ordered pair (x,\ y) that makes every equation in the system true is the solution to the system.

On one line, or on both?

Every point on a line makes that line’s equation true. Drag the point around the grid (or press Next for a tour): each equation gets a ✓ or a ✗. Only one point gets ✓ ✓.

Think Is (1,\ 3) the solution to the system y=x+2 and y=-x+6?
No. 3=1+2 ✓, but -1+6=5\neq3 ✗. The point is on the first line only. The solution to a system has to work in both equations.
2

The Solution Is the Point of Intersection

Every point on a line makes that line’s equation true. So a point that lies on both lines makes both equations true.

Graph the two equations on the same grid. The point of intersection (where the lines cross) is the solution to the system.
Example 1

Read the solution off the graph

The system y=2x+2 and y=-x+5 is graphed below. The lines cross at whole-number coordinates.

(a) State the solution: x= 1, y= 4
The lines cross 1 unit right and 4 units up from the origin: x=1,\ y=4.
Check: 2(1)+2=4 ✓ and -(1)+5=4 ✓
(b) Write the solution as an ordered pair.
\boldsymbol{(1,\ 4)}: always x first, then y.

Example 1 check: read it, then check it

Drop from the crossing straight down to the x-axis and straight across to the y-axis. Then substitute into both equations.

!
x first. (1,\ 4) and (4,\ 1) are different points. The check catches a swap: (4,\ 1) fails y=2x+2.
3

Solving a System by Graphing

1If an equation is not already y=mx+b, rewrite it in slope-intercept form.
2Graph both lines on the same grid, using each y-intercept and slope.
3Find where the lines cross.
4State that point as an ordered pair (x,\ y).

Step 1 with -y: for 2x-y=4, subtract 2x to get -y=-2x+4, then change every sign: y=2x-4.

Graphing one line from y=mx+b (from Unit 7). To graph y=-2x+3:
  1. The y-intercept is b=3: plot (0,\ 3).
  2. The slope is m=-2=\dfrac{-2}{1}: from (0,\ 3) go down 2, right 1 to (1,\ 1), then again to (2,\ -1).
  3. Draw a straight line through the points, with arrows on both ends.
Example 2

Graph both lines, find the crossing

Consider the system y=x-3 and y=-2x+3.

(a) Graph both equations on the grid, without using technology.
y=x-3: start at (0,\ -3), then up 1, right 1.
y=-2x+3: start at (0,\ 3), then down 2, right 1.
(b) State the solution to the system as an ordered pair.
The lines cross at \boldsymbol{(2,\ -1)}.
Check: 2-3=-1 ✓ and -2(2)+3=-1 ✓

Example 2 check: the four steps

Start each line at its y-intercept, step out the slope, draw the line. The crossing is the solution.

Step 1: getting y alone

An equation like 2x+y=1 has the x-term on the same side as y. To get y alone, do the same thing to both sides: subtract 2x from each side. Then write the x-term first, so it looks like y=mx+b.

!
The sign goes with the term. y=1-2x means y=-2x+1: the slope is -2, not 2. And with -y, change every sign at the end (Step 1): you want y, not -y.
Example 3

Rewrite first, then graph

Consider the system 2x+y=1 and y=x-5.

(b) Graph both equations on the grid, without using technology.
y=-2x+1: from (0,\ 1) go down 2, right 1.
y=x-5: from (0,\ -5) go up 1, right 1.
(a) Rewrite 2x+y=1 in slope-intercept form.
2x+y=1
Subtract 2x from each side: \boldsymbol{y=-2x+1}
(c) State the solution as an ordered pair.
\boldsymbol{(2,\ -3)}
Check: 2(2)+(-3)=1 ✓ and 2-5=-3 ✓

Example 3 check: rewrite, graph, cross

Step 1 matters this time: 2x+y=1 becomes y=-2x+1 before it can be graphed.

4

Checking a Solution

A point read off a hand-drawn graph is easy to get slightly wrong. So substitute it into both original equations.

Both true ✓ ✓
The solution is confirmed.
Either one false ✗
It is not the solution: the graph, or the reading of it, went wrong.
Example 4

Is it the solution?

Determine whether the given ordered pair is the solution to the system.

(a) (3,\ 1) for y=2x-5 and y=-x+4.
Substitute x=3, y=1 into each equation.
y=2x-5: 2(3)-5=6-5=1 ✓
y=-x+4: -(3)+4=1 ✓
Both are true, so (3,\ 1) is the solution.
(b) (2,\ 3) for y=3x-4 and y=-2x+9.
Substitute x=2, y=3 into each equation.
y=3x-4: 3(2)-4=2\neq3 ✗
y=-2x+9: -2(2)+9=5\neq3 ✗
Neither is true, so (2,\ 3) is not the solution.

When the check fails: find the mistake

A failed check is good news: it tells you something went wrong before you hand in a wrong answer. Look for the slip, fix the line, and check again.

Example 5

The whole process: rewrite, graph, state, check

Consider the system x+y=3 and y=2x-3.

(b) Graph both equations on the grid.
y=-x+3: from (0,\ 3) go down 1, right 1.
y=2x-3: from (0,\ -3) go up 2, right 1.
(a) Rewrite x+y=3 in slope-intercept form.
x+y=3
Subtract x from each side: \boldsymbol{y=-x+3}
(c) State the solution as an ordered pair.
\boldsymbol{(2,\ 1)}
(d) Check the solution in both original equations, x+y=3 and y=2x-3.
x+y=3: 2+1=3 ✓
y=2x-3: 2(2)-3=4-3=1 ✓
Both original equations are true, so (2,\ 1) is confirmed.

Example 5 check: all four steps, then the check

Check in the original equations, x+y=3 and y=2x-3, not only in the rewritten one: a slip in Step 1 would hide in the rewritten equation.

✓

Key ideas

A system is two equations taken together. Its solution is the one ordered pair (x,\ y) that makes both equations true.
On the graph, every point on a line fits that line’s equation, so the solution is the point of intersection: where the lines cross. Write it x first.
Solve by graphing: (1) rewrite as y=mx+b, (2) graph both lines from b and the slope, (3) find the crossing, (4) state it as (x,\ y).
Always check in both original equations. Both true ✓ ✓: confirmed. One false ✗: not the solution, so find the mistake.
