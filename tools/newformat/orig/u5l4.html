Where Graphs Meet the Axes: x- and y-Intercepts

Two spots on a graph are worth a closer look: where it crosses the bottom axis and where it crosses the side axis. These points are called intercepts. At each one, one of the coordinates is always 0. In a real situation they tell the start and the end of the story.

I can…
  • explain what an x-intercept and a y-intercept are, and why one coordinate is 0 at each
  • read the intercepts from a graph and write them as ordered pairs
  • find every intercept, even when a graph meets an axis more than once
  • find the intercepts in a table of values
  • explain what the intercepts mean in a real situation (the starting value, and when something reaches zero)

1

What an Intercept Is

An x-intercept is a point where a graph crosses the x-axis. A y-intercept is a point where it crosses the y-axis.

Every point on the x-axis has y=0, and every point on the y-axis has x=0. On a graph, read off the point where the graph meets the axis: the line at left meets the x-axis at (4,\ 0).

x-intercept
(\,\square,\ 0\,)
on the x-axis, so y=0
y-intercept
(\,0,\ \square\,)
on the y-axis, so x=0

So an x-intercept is the point where y=0, and a y-intercept is the point where x=0.

!
The zero goes in the other spot. A line that crosses the x-axis at 4 has x-intercept (4,\ 0), not (0,\ 4). The point is on the x-axis, so its y-coordinate is the zero.

Reading an intercept from a graph

Follow the graph to the axis. Read the number where it crosses, then write the point with a 0 in the other spot.

Examples 1 and 2

Reading one intercept

Each graph below shows a line.

Example 1
(a) State the coordinates of the point where the graph crosses the x-axis.
The line meets the x-axis at x=2, so the x-intercept is \boldsymbol{(2,\ 0)}.
(b) What is the value of y at that point?
y=\boldsymbol{0}: every point on the x-axis has y=0.
Example 2
(a) State the coordinates of the point where the graph crosses the y-axis.
The line meets the y-axis at y=2, so the y-intercept is \boldsymbol{(0,\ 2)}.
(b) What is the value of x at that point?
x=\boldsymbol{0}: every point on the y-axis has x=0.
2

Several Intercepts, and Intercepts from a Table

A graph can meet the x-axis more than once, so list every spot where the graph touches an axis.

Intercepts from a table

A table of values works the same way without a picture: the column (or row) where x=0 gives the y-intercept, and the column (or row) where y=0 gives the x-intercept.
!
Look for the 0, not for the first column. The intercepts are wherever a 0 shows up. If the table is out of order, the zero might be anywhere.
Examples 3 and 4

Two x-intercepts, and a table

Example 3 shows a curve; Example 4 shows several points on a relation.

Example 3
(a) State the coordinates of both x-intercepts.
The curve meets the x-axis twice: \boldsymbol{(-3,\ 0)} and \boldsymbol{(3,\ 0)}.
(b) State the coordinates of the y-intercept.
It crosses the y-axis at the lowest point, \boldsymbol{(0,\ -4)}.
Example 4
(a) Which ordered pair is the y-intercept?
Look for the column with x=0: it pairs with y=2, so the y-intercept is \boldsymbol{(0,\ 2)}.
(b) Which ordered pair is the x-intercept?
Look for the column with y=0: it pairs with x=-2, so the x-intercept is \boldsymbol{(-2,\ 0)}.
3

Intercepts in Real Situations

When a graph models a real situation, the y-intercept usually gives the starting value (before any time has passed), and the x-intercept usually tells when a quantity reaches zero.
y-intercept (0,\ \square)
the start
time is 0: nothing has happened yet
x-intercept (\square,\ 0)
the end
the amount has run out: it is 0

Reading the graph between the intercepts

To find an output, go up from the input to the graph, then across to the side axis. To find an input, go across from the output to the graph, then down.

Check a graph reading with the rate. $40 spent evenly over 8 weeks is 40÷8= $5 per week. After 4 weeks: 40−4×5= $20 left.
Example 5

The gift card

Malik loads $40 onto a gift card and spends it steadily; B is the balance after t weeks.

(a) What is the y-intercept of the graph? What does it represent here?
\boldsymbol{(0,\ 40)}. At t=0 weeks nothing has been spent: the starting balance of $40 on the card.
(b) What is the x-intercept of the graph? What does it represent here?
\boldsymbol{(8,\ 0)}. The balance reaches $0 at t=8: the card is empty after 8 weeks.
(c) Use the graph to estimate the balance remaining after 4 weeks.
Up from t=4 to the line, then across: B=\boldsymbol{\$20}. (Check: $5 per week, 40-4(5)=20.)
(d) Use the graph to estimate after how many weeks the balance is $10.
Across from B=10 to the line, then down: t=\boldsymbol{6} weeks. (Check: 40-6(5)=10 ✓)
✓

Key ideas

x-intercept: where a graph crosses the x-axis. It looks like (\square,\ 0): there y=0.
y-intercept: where a graph crosses the y-axis. It looks like (0,\ \square): there x=0.
List every one. A curve can meet the x-axis twice. In a table, look for the 0: x=0 gives the y-intercept, y=0 the x-intercept.
In a story: the y-intercept is the starting value ($40 on the card); the x-intercept is when it runs out (empty after 8 weeks).
