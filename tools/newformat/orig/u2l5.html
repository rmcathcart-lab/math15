Zero Exponents

An exponent counts how many times the base is multiplied. So what could 3^0 mean: 3 multiplied by itself zero times? Today we let a pattern answer that, then check it with the quotient law. The surprise: any nonzero base to the power 0 is 1, not 0.

I can…
  • use a pattern (divide by the base once more) to explain why a^0=1
  • use the quotient law to show the same thing: 5^4\div5^4=5^0=1
  • evaluate a power with exponent 0, like 9^0 or (-6)^0
  • see what the 0 is attached to: 5x^0=5, but (5x)^0=1
  • use the zero exponent law as one step in a bigger simplification
AN3 Demonstrate an understanding of powers with integral and rational exponents.

The Exponent Laws So Far

Lessons 1–4 gave us five laws (the last card holds two of them). Tap a card to flip it.

Product Lawmultiplying, same base
a^{m}\times a^{n}=a^{m+n}2^3\times2^4=2^7
Quotient Lawdividing, same base
a^{m}\div a^{n}=a^{m-n}7^6\div7^2=7^4
Power of a Powera power, raised to a power
(a^{m})^{n}=a^{mn}(x^3)^2=x^6
Power of a Product / Quotienta bracket, raised to a power
(ab)^{n}=a^{n}b^{n}\left(\dfrac{a}{b}\right)^{n}=\dfrac{a^{n}}{b^{n}}

Every one of them used a positive exponent. Nothing yet tells us what 3^0 means. 3^2=3\times3 is easy to picture, but multiplying 3 by itself 0 times is not an obvious idea.

Think Make a guess before we find out: what should 3^0 be? 0? 1? 3? Something else?
Most people guess 0. The pattern in Section 2 will show that 3^0=1.
2

Discovering the Rule: A Pattern

Drop the exponent by one and you divide by the base one more time:

3^4=81 
3^3=2781\div3
3^2=927\div3
3^1=39\div3
3^0=\ ?3\div3

The same “divide by the base once more” works for any nonzero base, because a^1=a, and a\div a is always 1. The pattern predicts a^0=1.

The warm-up said the same thing

The number of folds is the exponent: 3 folds make 2^3=8 layers. Now unfold, one fold at a time.

3

Confirming It with the Quotient Law

Look at 5^4\div5^4 two ways. By the quotient law it is 5^{4-4}=5^0. But it is also just a number divided by itself, which is 1. Both describe the same expression, so 5^0=1.

In general, a^n\div a^n=a^{n-n}=a^0, and a number divided by itself is 1. That gives the law:

Zero Exponent Law  For any base a\neq0,
a^{0}=1
!
It’s 1, not 0. 3^0=1. Zero factors of 3 leave nothing to multiply, and “nothing multiplied” is 1, the number that changes nothing.
!
The base can’t be 0. Just like a denominator can’t be 0: 0^0 would mean 0\div0, so 0^0 is undefined.
Example 1

Evaluating powers with exponent 0

Evaluate each power without a calculator.

(a) 4^{0}
4^0=\mathbf{1}
Any nonzero base to the power 0.
(b) 9^{0}
9^0=\mathbf{1}
(c) (-6)^{0}
(-6)^0=\mathbf{1}
The base -6 is nonzero, so the law applies.
(d) (-1)^{0}
(-1)^0=\mathbf{1}
Check (c) afterwards. Keep the brackets for a negative base: ((−)6)^0ENTER gives 1. Without them, (−)6^0 gives −1: only the 6 gets the exponent (more on that in Section 4).
4

Zero Exponents on Variables

The law works the same with a variable base: x^0=1 when x\neq0. The danger is what the exponent is attached to. Picture a fence around whatever the 0 reaches.

5x^{0}The 0 sits only on x:
5x^0=5\times1=\mathbf{5}
(5x)^{0}The brackets make 5x the base:
(5x)^0=\mathbf{1}
!
Same numbers, different answers. Always check: is the exponent on one factor, or on a whole bracket? A minus sign out front is outside the fence too: -4^0=-(4^0)=-1.
Example 2

Where is the 0 attached?

Simplify each expression.

(a) x^{0}
x^0=\mathbf{1}

5\times1
=\mathbf{5}
(c) (5x)^{0}
Whole bracket is the base.
=\mathbf{1}
(d) -2m^{0}
-2\times1
=\mathbf{-2}
(e) (-2m)^{0}
=\mathbf{1}
Example 3

True or false?

Identify each statement as true or false.

(a) 7y^{0}=1
False. The 0 is only on y: 7y^0=7\times1=7.
(b) (7y)^{0}=1
True. The brackets make 7y the base.
(c) x^{0}=0
False. x^0=1 for any x\neq0.
(d) -4^{0}=-1
True. Only the 4 is raised to 0: -(4^0)=-1.

5

Combining the Zero Exponent Law with the Other Laws

Often the zero exponent is just one step inside a bigger simplification.

1Spot any factor raised to the power 0. Check what the 0 is attached to.
2Replace that factor with 1.
3Finish with the laws you know: product, quotient, power of a power.
Example 4

One zero, then one more law

Simplify each expression.

(a) x^{5}\times x^{0}
x^{5+0}=\mathbf{x^{5}}
(Or: x^5\times1.)
(b) \dfrac{a^{6}}{a^{6}}
a^{6-6}=a^{0}
=\mathbf{1}
(c) 3b^{0}\times4b^{2}
3\times1\times4b^{2}
=\mathbf{12b^{2}}
(d) (2c^{3})^{0}\times5c^{4}
1\times5c^{4}
=\mathbf{5c^{4}}
Example 5

The zero exponent inside a bigger problem

Simplify each expression completely.

(a) (2x^{3}y^{0})^{2}\times3x
y^0=1, so the bracket is (2x^3)^2=4x^6.
4x^{6}\times3x=(4\times3)x^{6+1}=\mathbf{12x^{7}}
(b) \dfrac{(4a^{2}b^{0})^{2}}{2a^{3}}
b^0=1, so the top is (4a^2)^2=16a^4.
\dfrac{16a^{4}}{2a^{3}}=8a^{4-3}=\mathbf{8a}
Think In (a), what goes wrong if you forget that y^0=1 and keep the y in your answer?
You would write something like 12x^7y^0. That isn’t simplified: y^0 is just 1, so it disappears.
✓

Key ideas

The pattern: each step down the exponents divides by the base. 3^1=3, then 3\div3=1, so 3^0=1.
The quotient law agrees: 5^4\div5^4=5^0, and a number divided by itself is 1. So a^0=1 for any a\neq0.
What is the 0 attached to? 5x^0=5, but (5x)^0=1. And -4^0=-1, but (-4)^0=1.
In a bigger problem: spot the power of 0, replace it with 1, then finish with the other laws.
