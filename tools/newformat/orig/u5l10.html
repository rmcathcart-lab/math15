Function Notation: Graphs, Conversions, and Real-World Models

In Lesson 9 you put inputs into a rule like f(x)=2x+5. Today the same notation meets graphs and tables: read f(a) straight off a picture, switch between y= and f(x)=, and use function notation to tell a real story with units.

I can…
  • read f(a) from a graph (start on the horizontal axis) and find x when f(x)=b (start on the vertical axis)
  • rewrite f(x)=4x-3 as y=4x-3, and y=5x+2 as f(x)=5x+2
  • complete a table of values labelled h(x), and read it both ways
  • use a function to model a real situation, explain a value in words with units, and suggest a sensible domain and range

Warm-up

The Hiking Trail

h(d) = your height (m) after you walk d km along the trail. Use − and + to walk the hiker.

1
Find h(0). (the trailhead)
h(0)=200: the trailhead is 200 m high.
2
Find h(5). What is there?
h(5)=100: the lake, the lowest point on the trail.
3
Say h(7)=500 in words.
After walking 7 km, you are 500 m high: the summit.
4
Higher: h(2) or h(8)?
Neither. h(2)=400 and h(8)=400: two inputs, the same output.
!
The big one. A rest bench is 300 m high: h(d)=300. How many places on the trail could it be? Guess first.
A 1
B 2
C 3
D 4
C: 3 places. Go across from 300 on the height axis. The trail is 300 m high at d=1 (climbing to the lookout), d=3 (coming down) and d=6 (climbing to the summit).

1

Recall: Evaluating f(x)

Function notation replaces y with a function name such as f(x), g(x) or h(t). The notation f(a) says: put a in for the input everywhere it appears in the rule, then simplify.

If f(x)=3x+1, then f(2)=3(2)+1=7.
Every statement f(a)=b is a point (a,\ b) on the graph of f: input across, output up. So f(2)=7 is the point (2,\ 7).
2

Reading Function Values from a Graph

To find f(a): find a on the horizontal axis, move up or down to the graph, then read across to the vertical axis.
To find x when f(x)=b: start at b on the vertical axis, move across to the graph, then read up or down to the horizontal axis.
!
f(3) and f(x)=3 are different questions. In f(3) the 3 is an input: start on the horizontal axis. In f(x)=3 the 3 is an output: start on the vertical axis.
Example 1

Reading a graph both ways

The graph of a function f is shown. Use it to answer both parts.

(a) Use the graph to determine  i) f(-3)   ii) f(0)   iii) f(2)
Go to the x-value, up or down to the line, then across to the vertical axis.
i) f(-3)=\boldsymbol{-1}   ii) f(0)=\boldsymbol{2}   iii) f(2)=\boldsymbol{4}
(b) Use the graph to determine the value of x if  i) f(x)=-2   ii) f(x)=3   iii) f(x)=6
Work backwards: start on the vertical axis, across to the line, then up or down to the x-axis.
i) x=\boldsymbol{-4}   ii) x=\boldsymbol{1}   iii) x=\boldsymbol{4}
3

Converting Between y= Notation and f(x) Notation

The two forms describe exactly the same rule: f(x) and y name the very same output, so f(x)=4x+5 and y=4x+5 are the same equation.

function notation
x-y notation
f(x)=4x+5
y=4x+5
To convert one way, replace the function name and its bracket, such as f(x), with y. To convert back, replace y with a function name and bracket. The right side never changes.
Example 2

Switching notations

(a) Write each in x-y notation.   (b) Write each in function notation.

(a) i) f(x)=4x-3
Replace f(x) with y:
\boldsymbol{y=4x-3}
(a) ii) g(t)=t+6
Here the input is t, so the variables are t and y:
\boldsymbol{y=t+6}
(b) i) y=5x+2
Replace y with a name and its input:
\boldsymbol{f(x)=5x+2}
(b) ii) y=9-x
\boldsymbol{f(x)=9-x}
(Any name works: g(x), h(x), …)
4

Function Notation in Tables

A table can be written in function notation too: the top row lists the inputs x, and the bottom row lists the matching outputs, labelled f(x) or h(x) instead of y. Read a value directly, or fill a missing entry by evaluating the rule.

Example 3

A table in function notation

Let h(x)=3x+3.

(a) Complete the table of values.
x012345
h(x)
x012345
h(x)369121518
h(0)=3(0)+3=3,  h(1)=3(1)+3=6, … Each step of 1 in x adds 3 to the output.
(b) Use your completed table to state the value of h(4).
Read the column x=4:  h(4)=\boldsymbol{15}
(c) Use your completed table to determine the value of x for which h(x)=15.
Search the bottom row for 15: it sits under x=4. So x=\boldsymbol{4}.
(b) and (c) are the same fact read in opposite directions.
5

Real-World Function Models

Earnings, height, distance and cost often change by a rule that can be written in function notation. Evaluate the rule to answer the question, then always interpret the value in words with the correct units.

Input given (like E(6)): put it into the rule. One answer.
Output given (like “she earned $56”): set the rule equal to it and work backwards.
Example 4

Walking dogs

Jasmine earns money walking dogs. Her earnings are modelled by E(n)=8n, where E(n) is her total earnings, in dollars, for walking n dogs.

(a) Complete the table of values.
n12345
E(n)
n12345
E(n)816243240
E(n)=8n, so multiply each input by 8.
(b) Determine the value of E(6), and explain what it means in this situation.
E(6)=8(6)=\boldsymbol{48}
Meaning: walking 6 dogs earns Jasmine $48.
(c) How many dogs did Jasmine walk if she earned $56?
Here the output is known, so solve:
56=8n, so n=\dfrac{56}{8}=\boldsymbol{7} dogs
(d) Suggest an appropriate domain for this function, given that Jasmine can realistically walk at most 8 dogs in one day.
A number of dogs must be a whole number and cannot be more than 8:
D=\{0,\ 1,\ 2,\ 3,\ 4,\ 5,\ 6,\ 7,\ 8\}
(Starting at 1 is also fine if you count only days she actually works.)

Check Example 4: dots, not a line

You can’t walk 2.5 dogs. When the input counts whole things, the graph is separate dots, and the domain is a list of whole numbers.

Example 5

A burning candle

A candle burns down at a steady rate. Its height is modelled by h(t)=20-2t, where h(t) is the height, in centimetres, t minutes after it is lit.

(a) Sketch the graph of the function on the grid.
Plot the start (0,\ 20) and the burn-out point (10,\ 0), then join them: the height drops 2 cm each minute.
(b) Determine the value of h(3).
h(3)=20-2(3)=20-6=\boldsymbol{14}
(c) Write in words the meaning of h(3).
Three minutes after the candle is lit, it is 14 cm tall.
(d) Evaluate h(0) and explain its significance.
h(0)=20-2(0)=\boldsymbol{20}. At t=0 nothing has burned yet: the candle’s original height, 20 cm (the vertical intercept).
(e) How many minutes will it take for the candle to burn out completely (height =0)?
Set h(t)=0: 0=20-2t, so 2t=20 and t=\boldsymbol{10} minutes.
(f) Suggest an appropriate domain and range for the function h(t).
Time runs from lighting the candle until it is gone; the height runs from 0 up to 20 cm (any value in between):
D:\ 0\le t\le 10 (minutes)   R:\ 0\le h(t)\le 20 (cm)

Check Example 5: the candle and its graph

Where does the model stop?

The rule h(t)=20-2t will happily take any number. The candle won’t. A sensible domain keeps only the inputs that make sense in the story.

✓

Key ideas

Graph, forwards: f(a) starts at a on the horizontal axis: up or down to the graph, across to read. Backwards: f(x)=b starts at b on the vertical axis.
Convert: f(x) and y are the same output. f(x)=4x-3 ⇄ y=4x-3. The right side never changes.
Tables: top row inputs, bottom row outputs h(x). h(4)=15 and “h(x)=15 when x=4” are the same fact read both ways.
Models: answer in words with units: h(3)=14 means 3 minutes after lighting, the candle is 14 cm tall. The domain keeps only inputs that make sense.
